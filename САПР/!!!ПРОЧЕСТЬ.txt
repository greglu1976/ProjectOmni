
для работы требуется

1. config.ini - конфигурация РЭ для устройств
2. dictionary.json - словарь аббревиатур
3. Monteserrat-Regular.ttf - шрифт для софта
4. origin.docx - шаблон для бланка уставок
5. origin_summ.docx - шаблон для суммарной таблицы сигналов

можно удалять
1.summ_table_templ.docx - подготовленные шаблон для заполнения суммарной таблицы, каждый раз перегенерируется заново
2.temp.docx  - подготовленные шаблон для заполнения бланка уставок, каждый раз перегенерируется заново

Для версий 0.5.х
1. devices.ini - конфигурация устройств
2. dictionary.json - словарь аббревиатур
3. origin.docx - шаблон для бланка уставок
4. fbdata.db - sqlite база данных функций РЗА и плат
5. fsu.json - состав функций ФСУ по версиям (определяется из кода заказа берется устройство ДЗТ2, Т , ОЛ и тд и берется версия ФСУ из кода заказа 2.1 и тд)
6. Папка gui - там шрифт для приложения, темы для приложения и иконка приложения
