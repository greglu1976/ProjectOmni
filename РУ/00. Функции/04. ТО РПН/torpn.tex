\color{uniblue}\section[Выбор уставок функции блокировки устройства РПН трансформатора]{\sloppy Выбор уставок функции блокировки устройства РПН \mbox{трансформатора}} 
\color{black}

\begin{enumerate}[label=\arabic{section}.\arabic{enumi}, labelsep=7pt, leftmargin=0pt, itemindent=60pt, align=left, nosep]

\item
Во избежание поломок устройства РПН трансформатора, необходимо не допускать его работы при превышении максимально допустимого тока через устройство РПН, определяемого его техническими характеристиками.
Ток срабатывания функции блокировки РПН определяется по выражению:
\begin{equation}
    \label{eq:torpn1}
    %I_{\textsl{ср}} \ge \frac{I_{\textsl{макс.РПН}}} {K_{\textsl{отс}}\cdot{K_{\textsl{в}}}},
    I_{\textsl{бл.РПН}} = {K_{\textsl{отс}}}\cdot {I_{\textsl{макс.РПН}}},
    \end{equation}
    \begin{eqexpl}[15mm]
    \item{$I_{\textsl{макс.РПН}}$} максимальное допустимое значение тока устройства РПН, А;
    \item{$K_{\textsl{отс}}$} коэффициент отстройки, принимается равным 0,95.
    %\item{$K_{\textsl{в}}$} коэффициент возврата, принимается равным 1,05.
    \end{eqexpl}

\item
В общем случае, при неизвестных технических характеристиках устройства РПН, допустимо принять его номинальный ток равным номинальному току обмотки стороны, на которой он установлен, тогда ток срабатывания функции блокировки РПН будет определяться по выражению:
\begin{equation}
    \label{eq:torpn2}
    %I_{\textsl{ср}} \ge \frac{K_{\textsl{пер}}\cdot I_{\textsl{ном.ст.РПН}}} {K_{\textsl{отс}}\cdot{K_{\textsl{в}}}},
    I_{\textsl{бл.РПН}} = {K_{\textsl{отс}}}\cdot {K_{\textsl{пер}}}\cdot {I_{\textsl{ном.ст.РПН}}},
    \end{equation}
    \begin{eqexpl}[15mm]
    \item{$I_{\textsl{ном.ст.РПН}}$} номинальное значение тока стороны трансформатора с устройством РПН, А;
    \item{$K_{\textsl{пер}}$} коэффициент допустимой перегрузки устройства РПН, принимается равным 2,0 (ГОСТ 24126-80);   
    \item{$K_{\textsl{отс}}$} коэффициент отстройки, принимается равным 0,95.
    %\item{$K_{\textsl{в}}$} коэффициент возврата, принимается равным 1,05.
    \end{eqexpl}

\end{enumerate}
