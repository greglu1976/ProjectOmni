\color{unidarkgreen}{\subsection{Логика отключения смежного Т}}
\color{black}

\subsubsection{Общие сведения}

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{subsubsection}.\arabic*,  align=left, labelsep=4pt, leftmargin=0pt, itemindent=57pt]

\item
Ввод в работу логики отключения смежного трансформатора осуществляется с помощью уставки
\textbf{«ЛО смеж Т»}. Оперативный ввод/вывод ЛО см. Т от ТЗНП производится с помощью БУ (блока
управления функциями) «Вывод ЛО смеж. Т». 

\item
С целью исключения возникновения недопустимого режима работы параллельного
трансформатора с изолированной нейтралью при замыкании на землю одной фазы. Предусматривается
возможность первым действием сформировать сигнал \textit{«Откл. смеж. Т»} на отключение выключателя
стороны ВН смежного трансформатора. Логика отключения смежного трансформатора формируется по
пуску ТЗНП ВН с независимой выдержкой времени, которая задается уставкой \textbf{«Тср ТЗНП откл смеж
Т»}.
