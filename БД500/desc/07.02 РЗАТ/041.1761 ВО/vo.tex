\color{unidarkgreen}{\subsection{Внешнее отключение}}
\color{black}

\begin{enumerate}

\item
Внешнее отключение предназначено для приема внешних сигналов и формирования требуемого действия на отключение выключателей всех сторон автотрансформатора. 

\item
Уставки ВО представлены в таблице \ref{app_set:vo}. На рисунке \ref{pic_vo:VO} приведен алгоритм работы ВО. 

\begin{figure}[H]
\centering
\includegraphics[width=0.8\textwidth,height=0.8\textheight,keepaspectratio]{\fbpath/07.02 РЗАТ/041.1761 ВО/img/VO.pdf}
\captionof{figure}{Функциональная схема логики ВО}\label{pic_vo:VO}
\end{figure}

\item
В составе логики внешнего отключения предусмотрен прием трех сигналов внешнего отключения \textbf{«Внеш. откл1(2,3)»} с возможность контроля по току. ВО-1(2,3) вводится в работу программным переключателем \textbf{«ВО-1(2,3)»}. Контроль по току определяется программным переключателем \textbf{«Конт I ВО-1(2,3)»}, а порог срабатывания тока задается уставкой \textbf{«Iср ВО-1(2,3)»}. Действие внешнего отключения осуществляется с регулируемыми независимыми выдержками времени \textbf{«Тср ВО-1(2,3)»}.

\item
Режим действия внешнего отключения задается с помощью программного переключателя \textbf{«Режим ВО-1(2,3)»}:
\begin{itemize}
\item \textit{«Без АПВ»} -- Внешнее отключение с запретом АПВ;
\item \textit{«С АПВ»} -- Внешнее отключение без запрета АПВ.
\end{itemize} 

\item
Оперативный ввод/вывод внешнего отключения производится с помощью БУ (блоков управления функциями) \textit{«Вывод ВО»}. 

\end{enumerate}
