\color{unimain}{\subsection{Максимальная токовая защита}}
\color{black}

\begin{enumerate}

\item
Максимальная токовая защита с комбинированным пуском по напряжению предназначена для резервирования основных защит автотрансформатора и резервирования отключения КЗ на шинах.

\item
Уставки МТЗ представлены в таблице \ref{app_set:mtz}.

\item
В составе логики максимальной токовой защиты предусмотрено две ступени МТЗ, ввод в работу которых осуществляется с помощью программных переключателей \textbf{«МТЗ-1(2)»}. С помощью уставки \textbf{«ИО МТЗ»} имеется возможность выбрать по фазным или линейным токам (по разности токов) будут работать измерительные органы МТЗ.

\item
На рисунке \ref{pict_mtz:MTZ} приведен алгоритм работы МТЗ-1, выполнение алгоритма работы ступени МТЗ-2 аналогичное.

\item
Ток срабатывания ступеней МТЗ задается с помощью уставок \textbf{«Iср МТЗ-1(2)»}, а выдержки времени срабатывания ступеней регулируются уставками \textbf{«Тср МТЗ-1(2)»}.

\item
Имеется возможность задать различные режимы работы ступеней МТЗ при возникновении неисправности в цепях напряжения. Вариант действия логики направленных ступеней МТЗ при срабатывании БНН задается программными переключателями \textbf{«Режим БНН МТЗ-1(2)»}, имеющими три положения:
\begin{itemize}
\item \textit{«Выведено»} -- режим работы ступени не зависит от БНН;
\item \textit{«ОНМ»} – ступень переводится в ненаправленный режим работы;
\item \textit{«МТЗ»} – при срабатывании БНН ступень выводится из работы. Однако, если ступень задана ненаправленной, то она останется в работе независимо от срабатывания БНН. 
\end{itemize}

\item
Для обеспечения несрабатывания МТЗ от бросков намагничивающего тока предусмотрена блокировка ступеней МТЗ по содержанию второй гармоники в фазном или линейном токе в зависимости от уставки \textbf{«ИО МТЗ»}. Ввод в работу БНТ МТЗ осуществляется с помощью уставки \textbf{«БНТ МТЗ»}. Блокировка основана на контроле отношения действующего значения второй гармоники тока к основной гармонике. Ступени МТЗ блокируются при превышении данного соотношения пороговой величины, заданной уставкой \textbf{«I2г/I1г МТЗ»}. Наличие функции блокировки от бросков намагничивающего тока задается для каждой ступени отдельно с помощью программных переключателей \textbf{«Режим БНТ МТЗ-1»} и \textbf{«Режим БНТ МТЗ-2»}. Для предотвращения излишней блокировки при больших токах КЗ, сопровождающихся насыщением ТТ, блокировка выводится из действия при превышении тока основной гармоники выше уставки \textbf{«Iср БНТ МТЗ»}.

\item
Для повышения чувствительности, предусмотрена возможность пуска ступени МТЗ от комбинированного пускового органа напряжения своей стороны (КПОН СШ), которая задается программными переключателями \textbf{«Режим КПОН СШ МТЗ-1(2)»} и напряжения низкой стороны (КПОН НН), которая задается программными переключателями \textbf{«Режим КПОН НН МТЗ-1(2)»}.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%% ОНМ 

\item
Направленность МТЗ обеспечивается органами направления мощности, выполненными по 90-градусной схеме, с парами токов и напряжений Ia и Ubc, Ib и Uca, Ic и Uab. Направление мощности определяется по величине фазового угла между током и напряжением отдельно для каждой пары сигналов. Разрешение работы от органа направленности МТЗ будет происходить от пары сигналов с максимальным током. За положительное направление векторов принято вращение против часовой стрелки. Углы максимальной чувствительности ОНМ откладываются от линейных напряжений и задаются уставками \textbf{«Фмч ОНМ в АТ»} и \textbf{«Фмч ОНМ в сеть»}. Уставки по углам максимальной чувствительности рекомендуется задавать для ОНМ в АТ – 45º, а для ОНМ в сеть –225º. Ширина зоны срабатывания ± 85º от угла максимальной чувствительности. Величина тока работы ОНМ 0,05$\cdot I_{\textsl{ном}}$, величина напряжения работы ОНМ 0,01$\cdot U_{\textsl{ном}}$.

\item
Для выбора режима направленности по мощности предусмотрен программный переключатель \textbf{«Направл МТЗ-1(2)»}, имеющий три положения:
\begin{itemize}
\item \textit{«Ненапр»} -- ступень выполнена ненаправленной;
\item \textit{«В АТ»} -- ступень выполнена прямонаправленной в сторону АТ;
\item \textit{«В сеть»} -- ступень выполнена обратнонаправленной в сторону сети.
\end{itemize}

\item
Оперативный ввод/вывод МТЗ производится с помощью БУ (блоков управления функциями) \textit{«Вывод МТЗ»}. 

\item
Пуски степеней МТЗ направленные в сеть, действуют в логику предварительного деления своей стороны АТ. С помощью выдержек времени в логике деления \textbf{«Тср МТЗ-1(2) на СВ»}, \textbf{«МТЗ-1(2) на В сеч»} и \textbf{«Тср МТЗ-1(2) на В»}, первым действием формируются сигналы на разделение секции (отключение СВ) или деление по сечению (отключение В сечения), вторым действием формируются сигналы на отключение выключателей своей стороны с пуском УРОВ и запретом АПВ. Действие срабатывания ступеней МТЗ предусматривает отключение АТ со всех сторон с запретом АПВ и пуском УРОВ.

\item
В составе логики максимальной токовой защиты предусмотрен пуск автоматического ускорения ступеней МТЗ.

\item
С помощью программного переключателя \textbf{«Ступень АУ МТЗ в АТ»} имеется возможность выбрать от какой ступени МТЗ будет пускаться автоматическое ускорение при опробовании АТ. С помощью программного переключателя \textbf{«Ступень АУ МТЗ в сеть»} имеется возможность выбрать от какой ступени МТЗ будет пускаться автоматическое ускорение при опробовании ошиновки АТ или системы шин.

\item
Дополнительно предусмотрена возможность пуска ускорения от ненаправленного ИО ступени МТЗ c контролем броска намагничивающего тока, который задается программным переключателем \textbf{«Режим БНТ АУ МТЗ ненапрв»}. С помощью программного переключателя \textbf{«Ступень АУ МТЗ ненапр»} имеется возможность выбрать от какого ненаправленного ИО ступени МТЗ будет пускаться автоматическое ускорение при
включении выключателя.

\item
С помощью программного переключателя \textbf{«ОУ МТЗ»} имеется возможность ввода в работу оперативного ускорения. С помощью программного переключателя \textbf{«Ступень ОУ МТЗ в АТ»} имеется возможность выбрать от какой ступени МТЗ будет пускаться оперативное ускорение при выводе основных защит АТ. С помощью программного переключателя \textbf{«Ступень ОУ МТЗ в сеть»} имеется возможность выбрать от какой ступени МТЗ будет пускаться оперативное ускорение при выводе защиты ошиновки АТ или системы шин.

\item
Дополнительно предусмотрена возможность пуска ускорения от ненаправленного ИО ступени МТЗ c контролем броска намагничивающего тока, который задается программным переключателем \textbf{«Режим БНТ ОУ МТЗ ненапр»}. С помощью программного переключателя \textbf{«Ступень ОУ МТЗ ненапр»} имеется возможность выбрать от какого ненаправленного ИО ступени МТЗ будет пускаться оперативное ускорение.


\end{enumerate}
