\color{black}

\begin{enumerate}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%  ОБЩИЕ СВЕДЕНИЯ %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\item Общие сведения

\begin{enumerate}

\item
Блокировка при качаниях (БК) предназначена для исключения ложных срабатываний ДЗ при возникновении качаний и асинхронном ходе.
\item 
В устройстве реализовано два способа блокировки:
\begin{itemize}
	\item по приращению токов прямой и обратной последовательности -- БК-I;
	\item по скорости изменения величины сопротивления $dZ/dt$ -- БК-Z.
\end{itemize}

\end{enumerate}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%% БК-I %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\item\label{sec:bki} Блокировка по приращению токов прямой и обратной последовательности (БК-I)
\begin{enumerate}

\item 
БК-I принимает сигналы от чувствительного и грубого измерительных органов (ИО), контролирующих приращения токов прямой и обратной последовательностей. На выходе блокировки при качаниях формируется два сигнала:

\begin{itemize}
	\item \textit{БК-I-б} -- вводит в работу быстродействующие ступени ДЗ;
	\item \textit{БК-I-м} -- вводит в работу медленнодействующие ступени ДЗ.
\end{itemize}

\item 
Пороги срабатывания ИО, реагирующих на несимметричные КЗ, задаются с помощью уставок \textbf{«dI2 чув»} и \textbf{«dI2 груб»}. Пороги срабатывания ИО, реагирующих на симметричные КЗ, задаются с помощью уставок \textbf{«dI1 чув»} и \textbf{«dI1 груб»}. Срабатывание чувствительных ИО разрешает ввод в работу быстродействующих ступеней (сигнал \textit{«БК-I: Срабатывание БК-I-б»}) на время, задаваемое уставкой \textbf{«Тв БК-I-б чув»}, с последующей блокировкой ввода быстродействующих ступеней ДЗ от чувствительных ПО на время \textbf{«Тв БК-I-м»}. Если в течение времени ввода медленнодействующих ступеней \textbf{«Тв БК-I-м»} срабатывает грубый ИО, то сигнал \textit{«БК-I: Срабатывание БК-I-б»} повторно введется в работу, на время задаваемое уставкой \textbf{«Тв БК-I-б груб»}.  Грубый ИО предусмотрен для обеспечения повторного пуска быстродействующих ступеней ДЗ при переходе внешнего КЗ во внутреннее. Срабатывание чувствительного или грубого ИО действует на ввод медленнодействующих ступеней ДЗ на время, задаваемое уставкой \textbf{«Тв БК-I-м»}. В логике БК-I предусмотрен ускоренный возврат схемы при отключении выключателя, который вводится программным ключом \textbf{«Сброс БК-I от РПО»}.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%% БК-Z %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\item\label{sec:bki} Блокировка по скорости изменения величины сопротивления dZ/dt (БК-Z)
\begin{enumerate}

\item
БК-Z основан на измерении времени прохождения годографом полного сопротивления области между внешней и внутренней характеристик реле сопротивления.
Внутренняя область характеристики задается уставками:
\begin{itemize}
	\item \textbf{«Rср внутр. хар.»} – активное сопротивление срабатывания;
	\item \textbf{«Хср внутр. хар.»} – реактивное сопротивление срабатывания;
	\item \textbf{«Фхс»} – угол наклона характеристик.
\end{itemize}

\item
Внешняя характеристика срабатывания реле сопротивления отстоит от внутренней характеристики по оси R на величину $\Delta$R и по оси X на величину $\Delta$X.

\item
Значения параметров $\Delta$R и $\Delta$X регулируются уставками \textbf{«dR»} и \textbf{«dX»} соответственно.

\item
Уставка по скорости изменения Z задается выдержкой времени \textbf{«Тзад БК-Z»} – если в течение этого времени годограф сопротивления не пересёк зону контроля скорости изменения сопротивления, то ступени ДЗ, вводимые от БК-Z, заблокируются. Принудительный возврат схемы БК-Z задается выдержкой времени \textbf{«Тв БК-Z»}.

\begin{figure}[H]
\centering
\includegraphics[width=0.85\textwidth,height=0.85\textheight,keepaspectratio]{\fbpath/03.01 ЛВ/561.1471 БК/img/BK_Z.pdf}
\captionof{figure}{Функциональная схема БК-Z}\label{pict_bk:BK_Z}
\end{figure}

\item
При возникновении короткого замыкания вектор сопротивления скачкообразно переходит из области нагрузки в область срабатывания. При возникновении синхронных качаний вектор сопротивления появляется в области срабатывания и покидает её. Качания выявляются при прохождении по монотонной траектории. Логическая цепочка БК-Z выдаёт при этом запрет на срабатывание ступеней дистанционной защиты. Срабатывание измерительного органа $I_2$ БК-Z во время качаний приводит к быстрому возврату БК-Z, и таким образом, делает возможным отключение от дистанционной защиты. Порог срабатывания ИО $I_2$ БК-Z регулируется уставкой \textbf{«I2 БК-Z»}. Для БК-Z также предусмотрен ускоренный возврат схемы при отключении 
выключателя, который вводится программным ключом \textbf{«Сброс БК-Z от РПО»}.

\centering

\captionof{figure}{Характеристики реле сопротивления, используемые для блокировки при качаниях по скорости изменения сопротивления}\label{pict_bk:char_relay_res}
\end{figure}

\end{enumerate}
