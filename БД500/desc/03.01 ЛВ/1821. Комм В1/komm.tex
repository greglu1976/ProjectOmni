\color{unimain}{\subsection{Коммутация выключателя}}
\color{black}

\begin{enumerate}

\item
Функциональный блок коммутации выключателя предназначен для формирования сигнала, определяющего момент коммутации силового выключателя для функций РЗА.
В случае присоединения линии к системе через два выключателя для каждого из них можно задействовать свою логику коммутации.

\item
Сигнал коммутации выключателя формируется по приходу сигналов РКВ, РКО, сигналов включить от АПВ и ПАВ и внешнего сигнала коммутации. Для предупреждения срыва сигнала коммутации, предусмотрен подхват от реле контроля тока через электромагнит включения выключателя.

\item
Функциональная схема логики коммутации В1 приведена на рисунке \ref{pict_ksn:komm}. Функциональная схема логики коммутации В2 выполняется аналогично схеме логики коммутации В1.
