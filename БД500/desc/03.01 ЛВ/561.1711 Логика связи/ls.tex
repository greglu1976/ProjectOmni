\color{unidarkgreen}{\subsection{Логика связи (ЛС)}}
\color{black}

\begin{enumerate}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%  ОБЩИЕ СВЕДЕНИЯ %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\item
В устройстве предусмотрена возможность организации приема и передачи команды телеотключения и сигналов телеускорения для обеспечения быстрого селективного отключения КЗ на защищаемой ЛЭП. Прием и передача указанных сигналов могут осуществляться как через встроенный интерфейс связи устройства (при организации цифрового канала связи для ДЗЛ), так и с применением внешних устройств передачи аварийных сигналов и команд (УПАСК) для различных типов каналов связи (высокочастотных, оптических, цифровых сетей).

\item Телеотключение
\begin{enumerate}

\item
Формирование сигнала на отключение выключателя при приеме команды телеотключения может осуществляться с подтверждением от следующих сигналов:

\begin{itemize}
	\item \textit{«БК-I-м»} (контроль вводится программным переключателем \textbf{«Контр. Тоткл от БК-I-м»});
	\item пуск одной из ступеней ДЗ-ФФ или ДЗ-ФЗ (ступени выбираются программными переключателями \textbf{«Контр. Тоткл от ДЗ-ФФ»} и \textbf{«Контр. Тоткл от ДЗ-ФЗ»});
	\item срабатывание ИО ТЗНП выбранной ступени (выбор осуществляется программным переключателем \textbf{«Контр. Тоткл от ТЗНП»});
\end{itemize}

\item Телеускорение отключения трех фаз
\begin{enumerate}

\item
Прием сигнала телеускорения отключения трёх фаз (ТУ ОТФ) может осуществляться с контролем срабатывания:

\begin{itemize}
    \item направленного РС-ФФ-2 с охватом начала координата (вводится программным ключом \textbf{«Контр. РС-ФФ-2 с охв.»});
    \item направленного РС-ФФ-3 (вводится программным ключом \textbf{«Контр. РС-ФФ-3»});
    \item направленного РС-ФФ-4 (вводится программным ключом \textbf{«Контр. РС-ФФ-4»});
    \item направленного РС-ФЗ-2 (вводится программным ключом \textbf{«Контр. РС-ФЗ-2»});
    \item ИО четвертой ступени ТЗНП (вводится программным ключом \textbf{«Контр. ИО ТЗНП-4»}).
\end{itemize}

\item
При необходимости для РС можно ввести контроль от БНН программным ключом \textbf{«БНН РС»}.

\item
Блокировка от БНН вводится отдельно для каждой ступени ДЗ программными ключами \textbf{«БНН ДЗ-ФФ(ФЗ)-N»}.

\item
\textls[-25]{Для ИО ТЗНП-4 программным ключом \textbf{«Контр. ОНМНП-Р»} может быть введен контроль направленности. Переключателем \textbf{«БНН ИО ТЗНП-4»} можно задать два режима работы ИО ТЗНП-4 при срабатывании БНН:}
\begin{itemize}
    \item \textit{Вывод напр.} -- ИО ТЗНП-4 работает без контроля направленности;
    \item \textit{Вывод ИО ТЗНП} -- ИО ТЗНП-4 выводится из работы.
\end{itemize}

\item
Выдержка времени на срабатывание ТУ ОТФ регулируется уставкой \textbf{«Тср ТУ ОТФ»}.

\item
Передача разрешающего сигнала ТУ ОТФ на противоположный конец линии осуществляется при срабатывании внутренних защит устройства, кроме ТЗО.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%  ТЕЛЕУСКОРЕНИЕ ДЗ %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\item Телеускорение ступеней ДЗ
\begin{enumerate}

\item
Для реализации логики телеускорения ДЗ (ТУ ДЗ) предусмотрены прием и передача разрешающих либо блокирующих сигналов. Выбор режима работы выполняется переключателем \textbf{«Режим ТУ ДЗ»}, имеющим два положения:
\begin{itemize}
    \item \textit{Разр.} -- используется режим с использованием разрешающих сигналов;
    \item \textit{Блок.} -- используется режим с использованием блокирующих сигналов.
\end{itemize}

\item
При организации ТУ ДЗ с помощью разрешающих сигналов в случае КЗ на защищаемой ЛЭП происходит пуск прямонаправленной ступени ДЗ и формируется разрешающий сигнал для передачи на противоположный конец линии. Выбор прямонаправленной ступени ДЗ выполняется с помощью программных переключателей \textbf{«Прямонапр. ступень ДЗ-ФФ»} и \textbf{«Прямонапр. ступень ДЗ-ФЗ»}. Прямая направленность задается в соответствующих настройках самой ступени.

\item
Отключение КЗ осуществляется при получении разрешающего сигнала и наличии пуска прямонаправленной телеускоряемой ступени ДЗ.

\item
Для исключения неселективной работы ТУ ДЗ применяется блокировка при реверсе мощности. Для выявления режима реверса мощности используется обратнонаправленная ступень ДЗ. Выбор обратнонаправленной ступени ДЗ осуществляется переключателями \textbf{«Обратнонапр. ступень ДЗ-ФФ»} и \textbf{«Обратнонапр. ступень ДЗ-ФЗ»}. Обратная направленность задается в соответствующих настройках самой ступени. 

\item
Функциональная схема логики ТУ ДЗ приведена на рисунке \ref{pict_lo:tu_dz}.

\begin{figure}[H]
\centering
\includegraphics[width=0.9\textwidth,height=0.9\textheight,keepaspectratio]{\fbpath/03.01 ЛВ/561.1711 Логика связи/img/logic_TU_DZ.pdf}
\captionof{figure}{Функциональная схема логики ТУ ДЗ}\label{pict_lo:tu_dz}
\end{figure}

\item
Уставки ТУ ДЗ представлены в таблице \ref{app_set:ls}.

\item
Выдержка времени \textbf{«Тфикс обр. ст.»} обеспечивает фиксацию устойчивого пуска обратнонаправленной ступени ДЗ при КЗ на параллельной линии. Его значение должно быть меньше полного времени отключения повреждения на параллельной линии. Выдержка времени \textbf{«Тпрод обр. ст.»} обеспечивает продление сигнала о пуске обратнонаправленной ступени до срабатывания прямонаправленной ступени. По одновременному наличию продленного сигнала пуска обратнонаправленной ступени и появлению пуска прямонаправленной ступени фиксируется режим реверса мощности. Минимальное время действия блокировки при реверсе мощности определяется выдержкой времени \textbf{«Тв блок. ТУ ДЗ»}. 

\item
При фиксации режима реверса мощности блокируется формирование сигнала на отключение от ТУ ДЗ и передача разрешающего сигнала на противоположный конец линии.

\item
При организации ТУ ДЗ с помощью блокирующих сигналов используется обратнонаправленная ступень ДЗ, обеспечивающая передачу блокирующего сигнала на противоположный конец линии при внешних КЗ. Для снятия пуска блокирующего сигнала при обнаружении повреждения в прямом направлении в защищаемой зоне применяется прямонаправленная ступень ДЗ. Отключение КЗ осуществляется при отсутствии блокирующего сигнала и наличии пуска прямонаправленной телеускоряемой ступени ДЗ.

\item
Выдержка времени на срабатывание ТУ ДЗ регулируется уставкой \textbf{«Тср ТУ ДЗ»}.

\item
Выдержка времени \textbf{«Тпрод передачи ТУ ДЗ»} задает время продления передачи разрешающего сигнала на противоположный конец линии. 

\item
Действие на отключение от ТУ ДЗ и передача разрешающего сигнала на противоположный конец линии могут быть заблокированы при сквозных токах через ошиновку. Блокировка вводится программным ключом \textbf{«БСТО ТУ ДЗ»}.


\item
Для работы логики ТУ ДЗ необходимо, чтобы выбранные ступени ДЗ с обоих концов ЛЭП выявили повреждение. Однако в энергосистеме могут быть такие режимы, когда ток повреждения недостаточен для срабатывания защиты, например, короткое замыкание на конце защищаемой линии со слабым питанием. В таком случае не будет пуска ступени ДЗ как на срабатывание, так и на выдачу разрешающего сигнала, что приведёт к отказу логики ТУ ДЗ. Для устранения этого недостатка возможно применение логики отключения слабого конца (ЛОСК) с формированием эхо-сигнала.

\item
Эхо-сигнал формируется с выдержкой времени \textbf{«Тср эхо ТУ ДЗ»} (выдержка времени предназначена для отстройки от разновременного пуска защит по концам линии), если в течение 200 мс отсутствует пуск защит (МФТО, ТЗНП, ДЗ, АМТЗ).

\item
Длительность эхо-сигнала определяется выдержкой времени \textbf{«Тимп эхо ТУ ДЗ»}. Формирование нового эхо-сигнала блокируется на время, задаваемое уставкой \textbf{«Тбл эхо ТУ ДЗ»}, для исключения зацикливания логики.

\item
Эхо-сигнал действует на передачу разрешающего сигнала.

\item
Эхо-сигнал обеспечивает быстрое отключение линии со стороны «сильной» системы (S2), в некоторых случаях это может привести к увеличению тока со стороны «слабой» системы (S1) -- обеспечится каскадное отключение линии (см. рисунок \ref{pict_lo:logic_echo}). Если же после формирования эхо-сигнала не создаются условия каскадного отключения, то предусмотрена возможность отключения слабого конца по критерию минимального напряжения.

\begin{figure}[H]

\includegraphics[width=0.5\textwidth,height=0.5\textheight,keepaspectratio]{\fbpath/03.01 ЛВ/561.1711 Логика связи/img/logic_echo.pdf}
\captionof{figure}{Пояснение к принципу действия эхо-логики}\label{pict_lo:logic_echo}
\end{figure}

\item
Если сформирован эхо-сигнал, то сигнал на отключение формируется при снижении одного из контролируемых фазных напряжений ниже значения уставки \textbf{«Uср ЛОСК»} с контролем включенного положения выключателя. При снижении напряжения во всех фазах действие на отключение разрешено первые 100 мс для ограничения длительности отключающего воздействия. Критерий минимального напряжения блокируется при срабатывании БНН.

\item
Функциональная схема логики контроля минимального напряжения приведена на рисунке \ref{pict_lo:logic_LOSK}.

\vspace{2mm}

\captionof{figure}{Функциональная схема логики контроля минимального напряжения ЛОСК}\label{pict_lo:logic_LOSK}
\end{figure}

\item
Режим работы эхо-логики и ЛОСК для ТУ ДЗ определяется положением программного переключателя «Режим эхо ТУ ДЗ», имеющим четыре положения:
\begin{itemize}
    \item   \textit{Выведено} -- эхо-логика и ЛОСК выведены из работы;
	\item	\textit{ЛОСК} -- в работу введена только ЛОСК;
    \item   \textit{Эхо} -- в работу введена только эхо-логика;
    \item   \textit{Эхо + ЛОСК} -- в работу введены и эхо-логика, и ЛОСК.
\end{itemize}

Уставки контроля минимального напряжения ЛОСК представлены в таблице \ref{app_set:ls}.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%  ТЕЛЕУСКОРЕНИЕ ТЗНП %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\item Телеускорение ступеней ТЗНП
\begin{enumerate}

\item
Для реализации логики телеускорения ТЗНП (ТУ ТЗНП) предусмотрены прием и передача разрешающих либо блокирующих сигналов. Выбор режима работы выполняется переключателем «Режим ТУ ТЗНП», имеющим два положения:
\begin{itemize}
    \item \textit{Разр.} -- используется режим с использованием разрешающих сигналов;
    \item \textit{Блок.} -- используется режим с использованием блокирующих сигналов.
\end{itemize}

\item
При организации ТУ ТЗНП с помощью разрешающих сигналов в случае КЗ на защищаемой ЛЭП происходит пуск прямонаправленной ступени ТЗНП и формируется разрешающий сигнал для передачи на противоположный конец линии. Прямая направленность обеспечивается срабатыванием выбранной ступени ИО ТЗНП совместно с ОНМНП-Р -- выбор ступени ИО ТЗНП осуществляется программным переключателем \textbf{«Ступень ИО ТЗНП»}. 

\item
Для выявления режима реверса мощности используется ОНМНП-Б. Выдержка времени \textbf{«Тфикс ОНМНП-Б»} обеспечивает фиксацию устойчивого срабатывания ОНМНП-Б при КЗ на параллельной линии. Его значение должно быть меньше полного времени отключения повреждения на параллельной линии. Срабатывание ОНМНП-Б продлевается на время \textbf{«Тпрод ОНМНП-Б»}. По одновременному наличию продленного сигнала срабатывания ОНМНП-Б и появлению срабатывания ИО ТЗНП выбранной ступени совместно с ОНМНП-Р фиксируется режим реверса мощности. Минимальное время действия блокировки при реверсе мощности определяется выдержкой времени \textbf{«Тв блок. ТУ ТЗНП»}. 

\item
При фиксации режима реверса мощности блокируется формирование сигнала на отключение от ТУ ТЗНП и передача разрешающего сигнала на противоположный конец линии.

\item
При организации ТУ ТЗНП с помощью блокирующих сигналов используется ОНМНП-Б, обеспечивающий передачу блокирующего сигнала на противоположный конец линии при внешних КЗ. Для снятия пуска блокирующего сигнала при обнаружении повреждения в прямом направлении в защищаемой зоне применяется прямонаправленная ступень ТЗНП. Отключение КЗ осуществляется при отсутствии блокирующего сигнала и наличии пуска прямонаправленной телеускоряемой ступени ТЗНП.

\item
Выдержка времени на срабатывание ТУ ТЗНП регулируется уставкой \textbf{«Тср ТУ ТЗНП»}.

\item
Выдержка времени \textbf{«Тпрод передачи ТУ ДЗ»} задает время продления передачи разрешающего сигнала на противоположный конец линии.

\item
Разрешающий сигнал \textit{«ЛС/ ТУ ТЗНП: П. прям. ст. ТЗНП»} на противоположный конец линии выдается с контролем срабатывания ИО ТЗНП выбранной ступени совместно с ОНМНП-Р с контролем реверса мощности.

\item
Действие на отключение и выдача разрешающего сигнала могут быть заблокированы при выявлении броска намагничивающего тока. Для этого предусмотрен программный ключ \textbf{«БНТ ТУ ТЗНП»}.

\item
Для ТУ ТЗНП также возможно применение логики отключения слабого конца с формированием эхо-сигнала.

\item
Эхо-сигнал формируется с выдержкой времени \textbf{«Тср эхо ТУ ТЗНП»}, если в течение 200 мс отсутствует пуск защит (МФТО, ТЗНП, ДЗ, АМТЗ).

\item
Длительность эхо-сигнала определяется выдержкой времени \textbf{«Тимп эхо ТУ ТЗНП»}. Формирование нового эхо-сигнала блокируется на время, задаваемое уставкой \textbf{«Тбл эхо ТУ ТЗНП»}, для исключения зацикливания логики.

\item
Эхо-сигнал действует на выдачу разрешающего сигнала.

\item
