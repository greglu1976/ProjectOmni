\color{unidarkgreen}{\subsection{Логика связи (ЛС)}}
\color{black}

\begin{enumerate}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%  ОБЩИЕ СВЕДЕНИЯ %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\item
В устройстве предусмотрена возможность организации приема и передачи команды телеотключения и сигналов телеускорения для обеспечения быстрого селективного отключения КЗ на защищаемой ЛЭП. Прием и передача указанных сигналов могут осуществляться как через встроенный интерфейс связи устройства (при организации цифрового канала связи для ДЗЛ), так и с применением внешних устройств передачи аварийных сигналов и команд (УПАСК) для различных типов каналов связи (высокочастотных, оптических, цифровых сетей).

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%  ТЕЛЕОТКЛЮЧЕНИЕ %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\item Телеотключение
\begin{enumerate}

\item
Формирование сигнала на отключение выключателя при приеме команды телеотключения может осуществляться с подтверждением от следующих сигналов:

\begin{itemize}
	\item \textit{«БК-I-м»} (контроль вводится программным переключателем \textbf{«Контр. Тоткл от БК-I-м»});
	\item пуск одной из ступеней ДЗ-ФФ или ДЗ-ФЗ (ступени выбираются программными переключателями \textbf{«Контр. Тоткл от ДЗ-ФФ»} и \textbf{«Контр. Тоткл от ДЗ-ФЗ»});
	\item срабатывание ИО ТНЗНП выбранной ступени (выбор осуществляется программным переключателем \textbf{«Контр. Тоткл от ТЗНП»});
\end{itemize}

\item
Логика работы функции телеотключения приведена на рисунке \ref{pict_lo:ls1}.

Если программный ключ \textbf{«Прием Тоткл с контр.»} выведен, то сигнал на отключение выключателя при приеме сигнала телеотключения формируется без контролей.

\item
Передача команды телеотключения на противоположный конец линии осуществляется при срабатывании ЗНР, срабатывании внутреннего УРОВ или по сигналу срабатывания внешнего УРОВ, а также от внешнего сигнала \textit{«ЛС/Tоткл: Внеш. пуск Тоткл»}.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%  ТЕЛЕУСКОРЕНИЕ ТРЕХ ФАЗ %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\item Телеускорение отключения трех фаз
\begin{enumerate}

\item
Прием сигнала телеускорения отключения трёх фаз (ТУ ОТФ) может осуществляться с контролем срабатывания:

\begin{itemize}
    \item направленного РС-ФФ-2 с охватом начала координата (вводится программным ключом \textbf{«Контр. РС-ФФ-2 с охв.»});
    \item направленного РС-ФФ-3 (вводится программным ключом \textbf{«Контр. РС-ФФ-3»});
    \item направленного РС-ФФ-4 (вводится программным ключом \textbf{«Контр. РС-ФФ-4»});
    \item направленного РС-ФЗ-2 (вводится программным ключом \textbf{«Контр. РС-ФЗ-2»});
    \item ИО четвертой ступени ТНЗНП (вводится программным ключом \textbf{«Контр. ИО ТНЗНП-4»}).
\end{itemize}

\item
При необходимости для РС можно ввести контроль от БНН программным ключом \textbf{«БНН РС»}.

\item
Блокировка от БНН вводится отдельно для каждой ступени ДЗ программными ключами \textbf{«БНН ДЗ-ФФ(ФЗ)-N»}.

\item
\textls[-25]{Для ИО ТЗНП-4 программным ключом \textbf{«Контр. ОНМНП-Р»} может быть введен контроль направленности. Переключателем \textbf{«БНН ИО ТЗНП-4»} можно задать два режима работы ИО ТЗНП-4 при срабатывании БНН:}
\begin{itemize}
    \item \textit{Вывод напр.} -- ИО ТЗНП-4 работает без контроля направленности;
    \item \textit{Вывод ИО ТЗНП} -- ИО ТЗНП-4 выводится из работы.
\end{itemize}

\item
Выдержка времени на срабатывание ТУ ОТФ регулируется уставкой \textbf{«Тср ТУ ОТФ»}.

\item
Передача разрешающего сигнала ТУ ОТФ на противоположный конец линии осуществляется при срабатывании внутренних защит устройства, кроме ТЗО.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%  ТЕЛЕУСКОРЕНИЕ ДЗ %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\item Телеускорение ступеней ДЗ
\begin{enumerate}

\item
Для реализации логики работы ДЗ с использованием разрешающих сигналов предусмотрены прием и выдача сигнала телеускорения соответствующей ступени ДЗ (ТУ ДЗ).

\item
Прием сигнала ТУ ДЗ осуществляется с контролем пуска выбранных ступеней ДЗ-ФФ и ДЗ-ФЗ, направленных в линию -- выбор осуществляется программными переключателями \textbf{«Прямонапр. ступень ДЗ-ФФ»} и \textbf{«Прямонапр. ступень ДЗ-ФЗ»}. Прямая направленность задается в соответствующих настройках самой ступени.

\item
Для исключения неселективной работы ТУ ДЗ применяется блокировка при реверсе мощности. Для выявления режима реверса мощности используются обратнонаправленные ступени ДЗ-ФФ и ДЗ-ФЗ -- выбор ступеней осуществляется программными переключателями \textbf{«Обратнонапр. ступень ДЗ-ФФ»} и \textbf{«Обратнонапр. ступень ДЗ-ФЗ»}. Обратная направленность задается в соответствующих настройках самой ступени.

\item
Выдержка времени \textbf{«Тфикс об. ступени»} обеспечивает фиксацию устойчивого пуска обратнонаправленной ступени ДЗ при КЗ на параллельной линии. Его значение должно быть меньше полного времени отключения повреждения на параллельной линии. Выдержка времени \textbf{«Тпрод об. ступени»} обеспечивает продление сигнала о пуске обратнонаправленной ступени до срабатывания прямонаправленной ступени. По одновременному наличию продленного сигнала пуска обратнонаправленной ступени и появлению пуска прямонаправленной ступени фиксируется режим реверса мощности. 

\item
Минимальное время действия блокировки при реверсе мощности определяется выдержкой времени \textbf{«Тв блок. ТУ ДЗ»}.

\item
Выдержка времени на срабатывание ТУ ДЗ регулируется уставкой \textbf{«Тср ТУ ДЗ»}.

\item
Разрешающий сигнал \textit{«Выход ТУ ДЗ»} на противоположный конец линии выдается с контролем пуска прямонаправленной ступени ДЗ и с контролем реверса мощности.

\item
Функциональная схема логики ТУ ДЗ приведена на рисунке \ref{pict_lo:tu_dz}. Уставки ТУ ДЗ представлены в таблице \ref{app_set:ls}.

\begin{figure}[H]
\centering
\includegraphics[width=0.9\textwidth,height=0.9\textheight,keepaspectratio]{\fbpath/03.01 ЛВ/561.1711 Логика связи/img/logic_TU_DZ.pdf}
\captionof{figure}{Функциональная схема логики ТУ ДЗ}\label{pict_lo:tu_dz}
\end{figure}

\item
Для работы логики ТУ ДЗ необходимо, чтобы выбранные ступени ДЗ с обоих концов ЛЭП выявили повреждение. Однако в энергосистеме могут быть такие режимы, когда ток повреждения недостаточен для срабатывания защиты, например, короткое замыкание на конце защищаемой линии со слабым питанием. В таком случае не будет пуска ступени ДЗ как на срабатывание, так и на выдачу разрешающего сигнала, что приведёт к отказу логики ТУ ДЗ. Для устранения этого недостатка возможно применение логики отключения слабого конца (ЛОСК) с формированием эхо-сигнала.

\item
Эхо-сигнал формируется с выдержкой времени \textbf{«Тср эхо ТУ ДЗ»} (выдержка времени предназначена для отстройки от разновременного пуска защит по концам линии), если в течение 200 мс отсутствует пуск защит (МФТО, ТНЗНП, ДЗ, АМТЗ).

\item
Длительность эхо-сигнала определяется выдержкой времени \textbf{«Тимп эхо ТУ ДЗ»}. Формирование нового эхо-сигнала блокируется на время, задаваемое уставкой \textbf{«Тбл эхо ТУ ДЗ»}, для исключения зацикливания логики.

\item
Эхо-сигнал действует на выдачу разрешающего сигнала \textit{«Выход ТУ ДЗ»}.

\item
Эхо-сигнал обеспечивает быстрое отключение линии со стороны «сильной» системы (S2), в некоторых случаях это может привести к увеличению тока со стороны «слабой» системы (S1) -- обеспечится каскадное отключение линии (см. рисунок \ref{pict_lo:logic_echo}). Если же после формирования эхо-сигнала не создаются условия каскадного отключения, то предусмотрена возможность отключения слабого конца по критерию минимального напряжения.

\begin{figure}[H]
\centering
\includegraphics[width=0.55\textwidth,height=0.55\textheight,keepaspectratio]{\fbpath/03.01 ЛВ/561.1711 Логика связи/img/logic_echo.pdf}
\captionof{figure}{Пояснение к принципу действия эхо-логики}\label{pict_lo:logic_echo}
\end{figure}

\item
Если сформирован эхо-сигнал, то сигнал на отключение формируется при снижении одного из контролируемых фазных напряжений ниже значения уставки \textbf{«Uср ЛОСК»} с контролем включенного положения выключателя. При снижении напряжения во всех фазах действие на отключение разрешено первые 100 мс для ограничения длительности отключающего воздействия. Критерий минимального напряжения блокируется при срабатывании БНН.

\item
Функциональная схема логики контроля минимального напряжения приведена на рисунке \ref{pict_lo:logic_LOSK}. Уставки контроля минимального напряжения ЛОСК представлены в таблице \ref{app_set:ls}.

\vspace{2mm}
\begin{figure}[H]
\centering
\includegraphics[width=0.9\textwidth,height=0.9\textheight,keepaspectratio]{\fbpath/03.01 ЛВ/561.1711 Логика связи/img/logic_LOSK.pdf}
\captionof{figure}{Функциональная схема логики контроля минимального напряжения ЛОСК}\label{pict_lo:logic_LOSK}
\end{figure}

\item
Режим работы эхо-логики и ЛОСК для ТУ ДЗ определяется положением программного переключателя «Режим эхо ТУ ДЗ», имеющим три положения:
\begin{enumerate}[label=\arabic*)]
    \item   \textit{Откл.} -- эхо-логика и ЛОСК выведены из работы;
    \item   \textit{Эхо} -- в работу введена только эхо-логика;
    \item   \textit{Эхо + ЛОСК} -- в работу введены и эхо-логика, и ЛОСК.
\end{enumerate}

\end{enumerate}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%  ТЕЛЕУСКОРЕНИЕ ТЗНП %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\item Телеускорение ступеней ТНЗНП
\begin{enumerate}

\item
Прием сигнала ТУ ТНЗНП осуществляется с контролем срабатывания ИО ТНЗНП выбранной ступени совместно с РНМНП-Р -- выбор ступени ИО ТНЗНП осуществляется программным переключателем 
\textbf{«Ступень ИО ТНЗНП»}.

\item
Для выявления режима реверса мощности используется РНМНП-Б. Выдержка времени \textbf{«Тфикс РНМНП-Б»} обеспечивает фиксацию устойчивого срабатывания РНМНП-Б при КЗ на параллельной линии. Его значение должно быть меньше полного времени отключения повреждения на параллельной линии. Срабатывание РНМНП-Б продлевается на время \textbf{«Тпрод РНМНП-Б»}. По одновременному наличию продленного сигнала срабатывания РНМНП-Б и появлению срабатывания ИО ТНЗНП выбранной ступени совместно с РНМНП-Р фиксируется режим реверса мощности. Минимальное время действия блокировки при реверсе мощности определяется выдержкой времени \textbf{«Тв блок. ТУ ТНЗНП»}. 

\item
Выдержка времени на срабатывание ТУ ТНЗНП регулируется уставкой \textbf{«Тср ТУ ТНЗНП»}.

\item
Разрешающий сигнал \textit{«Выход ТУ ТНЗНП»} на противоположный конец линии выдается с контролем срабатывания ИО ТНЗНП выбранной ступени совместно с РНМНП-Р с контролем реверса мощности.

\item
Действие на отключение и выдача разрешающего сигнала могут быть заблокированы при выявлении броска намагничивающего тока. Для этого предусмотрен программный ключ \textbf{«БНТ ТУ ТНЗНП»}.

\item
Для ТУ ТНЗНП также возможно применение логики отключения слабого конца с формированием эхо-сигнала.

\item
Эхо-сигнал формируется с выдержкой времени \textbf{«Тср эхо ТУ ТНЗНП»}, если в течение 200 мс отсутствует пуск защит (МФТО, ТНЗНП, ДЗ, АМТЗ).

\item
Длительность эхо-сигнала определяется выдержкой времени \textbf{«Тимп эхо ТУ ТНЗНП»}. Фор\-ми\-ро\-ва\-ние нового эхо-сигнала блокируется на время, задаваемое уставкой \textbf{«Тбл эхо ТУ ТНЗНП»}, для исключения зацикливания логики.

\item
Эхо-сигнал действует на выдачу разрешающего сигнала \textit{«Выход ТУ ТНЗНП»}.

\item
Функциональная схема логики ТУ ТНЗНП приведена на рисунке \ref{pict_lo:tu_tnznp}. Уставки ТУ ТНЗНП представлены в таблице \ref{app_set:ls}.

\item
Если после формирования эхо-сигнала не создаются условия каскадного отключения, то предусмотрено отключение слабого конца по критерию минимального напряжения.

\item
Режим работы эхо-логики и ЛОСК для ТУ ТНЗНП определяется положением программного переключателя \textbf{«Режим эхо ТУ ТНЗНП»}, имеющим три положения:

    \item   \textit{Откл.} -- эхо-логика и ЛОСК выведены из работы;

    \item   \textit{Эхо + ЛОСК} -- в работу введены и эхо-логика, и ЛОСК.
