\color{unidarkgreen}{\subsection{Управление выключателем}}
\color{black}

\begin{enumerate}

\item
Функциональный блок управления выключателем предназначен для проведения операций отключения и включения выключателя. 

\item
Команда на отключение выключателя формируется при:
\begin{itemize}
    \item срабатывании УРОВ на себя;
    \item отключении при аварийном давлении элегаза (SF6) в ТТ;
    \item срабатывании ЗНФ;
	\item cрабатывании РЗ ШР(БСК);
	\item cрабатывании РЗ КР;
	\item cрабатывании РЗ ЛЭП;
	\item оперативном отключении.
\end{itemize}

\item
Функциональная схема управления выключателем приведена на рисунке \ref{pict_uv:uv}. Параметры настройки функции управления выключателем представлены в таблице \ref{app_set:uv}.

\vspace{2mm}
\begin{figure}[H]
\centering
\includegraphics[width=0.8\textwidth,height=0.8\textheight,keepaspectratio]{\fbpath/10.02 АУВ/УВ/img/uv.pdf}
\captionof{figure}{Функциональная схема управления выключателем}\label{pict_uv:uv}
\end{figure}

\item
Обеспечивается подхват действия на отключение при срабатывании датчиков тока, установленных в цепях ЭМО1, ЭМО2.

\item
При появлении сигнала блокировки отключении выключателя до начала процесса отключения последний блокируется.

\item
Команда на включение выключателя формируется при включении от АПВ или оперативном включении выключателя. Обеспечивается подхват действия на включение при срабатывании датчика тока, установленного в цепи ЭМВ.

\item
Операция включения выключателя блокируется при появлении сигнала на отключение выключателя (блокировка от многократных включений) или появление сигнала блокировки включения выключателя.

\item
Выходные цепи, действующие на включение выключателя, блокируются при переходе на управление через УПНКП.

\item
Функциональная схема управления выключателем УПНКП приведена на рисунке \ref{pict_uv:uv2}.

\vspace{2mm}
\begin{figure}[H]
\centering
\includegraphics[width=0.8\textwidth,height=0.8\textheight,keepaspectratio]{\fbpath/10.02 АУВ/УВ/img/uv2.pdf}
\captionof{figure}{Функциональная схема управления выключателем УПНКП}\label{pict_uv:uv2}
\end{figure}

\end{enumerate}
