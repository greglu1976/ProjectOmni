\color{unidarkgreen}{\subsection{Орган выявления броска тока намагничивания компенсационной обмотки (ОВ БНТ КО)}}
\color{black}

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic*,  align=left, labelsep=4pt, leftmargin=0pt, itemindent=57pt]

\item
Для обеспечения несрабатывания «МТЗ КО», «ТЗНП КО», «ТЗОП КО» при броске тока
намагничивания используется блокировка по содержанию 2 гармоники в токе. Блокировка основана на
контроле отношения действующего значения второй гармонике к первой в токах фаз. Имеется
возможность регулировать порог срабатывания блокировки, с помощью уставки \textbf{«I2г/I1г БНТ»}.
Блокировка по 2 гармонике выводится из действия при величине тока ниже 0,04Iном или превышении
током первой гармоники значения \textbf{«Iср БНТ»}.
