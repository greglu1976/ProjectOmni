\color{unidarkgreen}{\subsection{Cигнализация}}
\color{black}

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic*,  align=left, labelsep=4pt, leftmargin=0pt, itemindent=57pt]

\item
Устройство формирует выходное воздействие на сигнализацию «Срабатывание» по схеме «ИЛИ»
в следующих случаях:
\begin{itemize}
\item Срабатывание ДЗТ;
\item Срабатывание сигнальной ступени ГЗ АТ;
\item Срабатывание отключающей ступени ГЗ АТ;
\item Срабатывание ГЗ РПН;
\item Срабатывание сигнальной ступени ГЗ ЛРТ;
\item Срабатывание отключающей ступени ГЗ ЛРТ;
\item Срабатывание сигнальной ступени ДТ масла АТ;
\item Срабатывание отключающей ступени ДТ масла АТ;
\item Срабатывание сигнальной ступени  ДТ обмотки АТ;
\item Срабатывание отключающей ступени  ДТ обмотки АТ;
\item Срабатывание отсечного клапана АТ;
\item Срабатывание предохранительного клапана АТ;
\item Срабатывание сигнальной ступени ДТ масла ЛРТ;
\item Срабатывание сигнальной ступени ДТ масла ЛРТ;
\item Срабатывание отключающей ступени ДТ обмотки ЛРТ;
\item Срабатывание отключающей ступени ДТ обмотки ЛРТ;
\item Срабатывание предохранительного клапана ЛРТ;
\item Срабатывание реле давления ЛРТ;
\item Срабатывание ЗПО;
\item Срабатывание ЗП (ВН/СН/ОО);
\item Срабатывание КИ НН;
\item Срабатывание МТЗ НН.
\end{itemize}

\item
Устройство формирует выходное воздействие на сигнализацию «Неисправность» по схеме «ИЛИ»
в следующих случаях:
\begin{itemize}
\item Неисправность цепей тока ДЗТ;
\item Снижение изоляции цепей ГЗ АТ;
\item Снижение изоляции цепей ГЗ РПН;
\item Снижение изоляции цепей ДТ масла АТ;
\item Снижение изоляции цепей ДТ обмотки АТ;
\item Снижение изоляции цепей ДТ масла ЛРТ;
\item Снижение изоляции цепей ДТ обмотки ЛРТ;
\item Снижение изоляции цепей ДТ обмотки ЛРТ;
\item Снижение изоляции цепей РД обмотки ЛРТ;
\item Минимальный/максимальный уровень масла АТ;
\item Минимальный/максимальный уровень масла РПН;
\item Минимальный/максимальный уровень масла ЛРТ;
\item Отказ/неисправность системы охлаждения АТ;
\item Снижение изоляции цепей ГЗ ЛРТ;
\item Неисправность цепей оперативного тока.
\end{itemize}

\end{enumerate}
