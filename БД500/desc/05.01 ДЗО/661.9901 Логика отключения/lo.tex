%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%% Логика отключения %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\item \textbf{Логика отключения}

\begin{enumerate}

\item
Логика отключения предназначена для формирования сигналов отключения СШ, а также сигналов отключения и запрета АПВ присоединений. Ввод и вывод функции осуществляется либо посредством программного ключа \textbf{«ЛО СШ»}, либо с использованием внешнего сигнала \textit{«ЛО СШ: Вывод»}.

\item
Отключение СШ может осуществляться от ДЗО, ЧТО, от внутренних УРОВ присоединений, а также от внешних УРОВ и внешних защит (ЗНР ШСВ(СВ)).

\item
Для фиксации срабатывания защиты на время отключения всех выключателей, время выполнения цикла АПВ, а также включения всех присоединений участвующих в этом цикле применяется сигнал \textit{«ЛО СШ/ ЛО: Фикс. откл.»}, который продлевается на выдержку времени \textbf{«Тфикс откл СШ»}. Указанный сигнал используется в логике очувствления и запрета АПВ.

\item
Возможность действия внешних УРОВ на запрет АПВ задается с помощью программного ключа \textbf{«ЗАПВ от УРОВ Вn»}.

\item
Алгоритм работы логики отключения СШ приведен на рисунке \ref{pic_lo:Log_otkl_ssh}. Уставки логики отключения СШ приведены в таблице \ref{app_set:losh}.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%% Логика запрета АПВ %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\item \textbf{Логика запрета АПВ}

\begin{enumerate}

\item
Логика запрета АПВ предназначена для формирования запрета АПВ всех присоединений СШ, чтобы минимизировать вероятность повторного возникновения аварийной ситуации. 

\item
В устройстве предусмотрена реализация двух типов запрета АПВ: общий запрет АПВ и избирательный запрет АПВ при срабатывании ДЗО.

\item
Сигнал общего запрета АПВ формируется:
\begin{itemize}
\item при неуспешном АПВ;
\item при неполнофазном или полнофазном отказе выключателя питающего присоединения;
\item при срабатывании УРОВ;
\item при неуспешном опробовании;
\item при внешнем отключении;
\item при оперативном запрете АПВ.
\end{itemize}

\item
Неуспешное АПВ выявляется при повторном срабатывании защиты после первого отключения. Для фиксации первого отключения используется сигнал \textit{«ЛО СШ/ ЛО: Фикс. откл.»}, который формируется в логике отключения. Для того чтобы сигнал неуспешного АПВ формировался только при повторном срабатывании защиты, используется дополнительная выдержка времени, задаваемая уставкой \textbf{«Т АПВ 1пр СШ»}.
Данная выдержка времени должна охватывать время отключения всех выключателей, но при этом должна быть отстроена от времени включения первого присоединения в цикле АПВ.

\item
Неполнофазный или полнофазный отказ выключателя питающего присоединения выявляется по факту наличия напряжения после сформированного сигнала отключения. Отключение СШ фиксируется при наличии сигнала \textit{«ЛО СШ/ ЛО: Фикс. откл.»} и отсутствии сигнала \textit{«ЛО СШ/ ЛО: Отключение»}. Выдержка времени 25 мс необходима для отстройки от разновременности отключения фаз выключателя.

\item
Запрет АПВ от внешних защит осуществляется от сигналов срабатывания внешнего УРОВ присоединений.

\item
Запрет АПВ при отключении от УРОВ осуществляется при включении программного ключа \textbf{«ЗАПВ от УРОВ СШ»}.

\item
Запрет АПВ при неуспешном опробовании осуществляется при включении программного ключа \textbf{«ЗАПВ при опроб СШ»}.

\item
Ввод оперативного запрета АПВ при отключении осуществляется внешним сигналом \textit{«ЛО СШ/ ЗАПВ: Оперативный запрет АПВ»}. Оперативный запрет применяется в следующих случаях:
\begin{itemize}
\item при выполнении оперативных переключений с участием разъединителей, когда из-за возможных ошибок может сработать ДЗО и выполнение АПВ недопустимо;
\item после проведения ремонтных работ на СШ, когда существует вероятность включения на КЗ.
\end{itemize}

\item
