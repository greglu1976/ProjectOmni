\item Общие данные

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
Логика контроля цепей напряжения предназначена:
\begin{itemize}
\item для диагностики неисправности во вторичных цепях ТН;
\item для контроля отсутствия напряжения на СШ для ввода очувствления ДЗО при опробовании;
\item для контроля наличия напряжения на СШ для сброса автоматического очувствления ДЗО при успешном АПВ шин;
\item для запрета АПВ при наличии напряжения на СШ (при неполнофазном или полнофазном отказе выключателя питающего присоединения).
\end{itemize}

\item
Ввод и вывод в работу контроля исправности цепей напряжения на СШ осуществляется программным ключом: \textbf{«КЦН»}.

\item
При снижении значения хотя бы одного линейного напряжения ниже уставки \textbf{«ИО отсутствия U}, либо при срабатывании ИО наличия напряжения ОП (\textbf{«ИО наличия ОП U»}, через выдержку времени \textbf{«Ткцн»} формируется сигнал \textit{«Неиспр. ЦН»}.
Данный сигнал свидетельствует о наличии неисправности цепей напряжения ТН на СШ.

\item
Сигнал \textit{«Отсутствие U»} формируется, если значения всех линейных напряжений опускается ниже уставки \textbf{«ИО отсутствия U»} и одновременно отсутствует срабатывание ИО наличия напряжения ОП.
Данный сигнал свидетельствует об отсутствии напряжения и переходного режима на СШ.

\item
Сигнал \textit{«Наличие U при откл.»} формируется, если значение хотя бы одного линейного напряжения превысят уставку \textbf{«ИО наличия U»}, либо при срабатывании ИО наличия напряжения ОП (\textbf{«ИО наличия ОП U»}.
Данный сигнал свидетельствует о наличии напряжения на отключенной СШ и используется в логике запрета АПВ для факта наличия неполнофазного (полнофазного) отказа выключателя.

\item
Сигнал \textit{«Наличие U»} формируется, если значения всех линейных напряжений превысят уставку \textbf{«ИО наличия U»} и одновременно отсутствует срабатывание ИО наличия напряжения ОП.
Данный сигнал предназначен для сброса автоматического очувствления после успешного АПВ первого присоединения и свидетельствует о нормальном режиме работы и отсутствии переходного режима на СШ.
