\color{unimain}{\subsection{Орган выявления БНТ}}
\color{black}

\begin{enumerate}

\item
Для обеспечения несрабатывания МТЗ ВВ, ТЗНП ВВ, ТЗНП НВ, ТЗОП ВВ при броске тока намагничивания используется блокировка по содержанию 2 гармоники в токе. Блокировка основана на контроле отношения действующего значения второй гармонике к первой тока фаз. Имеется возможность регулировать порог срабатывания блокировки, с помощью уставки \textbf{«I2г/I1г БНТ ВВ»}. Блокировка по 2 гармонике выводится из действия при величине тока ниже 0,04Iном, при срабатывании \textbf{«Iср БНТ»}, а так же при выводе программной накладкой \textbf{«БНТ ВВ»}.

Уставки ОВ БНТ приведены в таблице \ref{app_set:bnt}. Алгоритм работы ОВ БНТ приведен на рисунке \ref{pict_bnt:BNT}.
