\color{unidarkgreen}{\subsection{Максимальная токовая защита}}
\color{black}

\begin{enumerate}

\item
Максимальная токовая защита (МТЗ) предназначена для резервирования действия основных быстродействующих защит при внутренних коротких замыканиях в БСК. Защита выполнена двухступенчатой. Измерительные цепи защиты включены на токи фаз А, В, С со стороны высоковольтных вводов БСК. При необходимости защита может быть включена на разность токов фаз (цифровая сборка токовых цепей в «треугольник»): 
\begin{equation}
\label{eq:Iabc}
\dot{I}'_{\textsl{A}} = \frac{ \dot{I}_{\textsl{A}} - \dot{I}_{\textsl{B}} }{\sqrt{3}} ; \dot{I}'_{\textsl{B}} = \frac{ \dot{I}_{\textsl{B}} - \dot{I}_{\textsl{C}} }{\sqrt{3}}; \dot{I}'_{\textsl{C}} = \frac{ \dot{I}_{\textsl{C}} - \dot{I}_{\textsl{A}}}{\sqrt{3}}
\end{equation}

\item
Защита имеет регулируемые значения по току и времени срабатывания. Каждая из ступеней защиты может выполнена с блокировкой по второй гармонике (отношению уровня второй гармоники к первой). Данная блокировка реализована на базе модуля \textbf{«ОВ БНТ ВВ»}. 

\item 
Уставки МТЗ ВВ приведены в таблице \ref{app_set:mtzvv}. Алгоритм работы МТЗ ВВ первой ступени приведен на рисунке \ref{pict:MTZ_VV}. Алгоритм работы МТЗ ВВ второй ступени выполнен аналогично.
