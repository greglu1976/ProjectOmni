\item Общие сведения

\begin{enumerate}

\item
Устройство содержит четыре ступени ДЗ от междуфазных замыканий и четыре ступени ДЗ от замыканий
на землю. Дистанционная защита предназначена для селективного отключения поврежденного элемента
электрической сети при всех видах коротких замыканий (КЗ), реагируя на снижение измеряемого
сопротивления в защищаемой зоне.

\item 
ДЗ селективно срабатывает:
\begin{itemize}
    \item при всех видах КЗ; 
    \item при переходе внешнего КЗ во внутреннее; 
    \item при КЗ, сопровождающемся снижением измеряемого напряжения до нуля.
\end{itemize}

\item 
Обеспечивается несрабатывание защиты:
\begin{itemize} 
\item при качаниях и асинхронном ходе; 
\item при неисправностях цепей напряжения;
\item при внешних КЗ с насыщением ТТ (при соблюдении заявленных производителем требований к ТТ); 
\item при бросках тока намагничивания без КЗ;
\item при внешних КЗ, даже если измеряемое напряжение снижается до нуля.
\end{itemize}

\item Каждая из ступеней ДЗ от междуфазных КЗ включает в себя три реле сопротивления (РС), использующие
для замера сопротивления  комплексные значения линейных напряжений и соответствующих им линейных
токов:
\begin{align}
	\vec Z_{AB} =  \frac{\vec U_A - \vec U_B}{\vec I_A - \vec I_B}\label{eq:groupZ1}, \\
	\vec Z_{BC} =  \frac{\vec U_B - \vec U_C}{\vec I_B - \vec I_C}\label{eq:groupZ2}, \\
	\vec Z_{CA} =  \frac{\vec U_C - \vec U_A}{\vec I_C - \vec I_A}\label{eq:groupZ3},
\end{align}

\begin{eqexpl}[20mm]
    \item{$ \vec U_{A}, \vec U_{B}, \vec U_{C} $} комплексные значения напряжений фаз А, В, С от ТН 1СШ;
	\vspace{2pt}
    \item{$ \vec I_{A}, \vec I_{B}, \vec I_{C} $} комплексные значения токов фаз А, В, С.
\end{eqexpl}

\medskip

\item 
Комплексные значения сопротивлений по контуру «фаза-земля» рассчитываются с учетом компенсации
тока нулевой последовательности:
\begin{align}
\vec Z_{A} =  \frac{\vec U_A }{\vec I_A + \vec K \cdot  3 \vec I_0}\label{eq:groupZ11}, \\
\vec Z_{B} =  \frac{\vec U_B }{\vec I_B + \vec K \cdot  3 \vec I_0}\label{eq:groupZ12}, \\
\vec Z_{C} =  \frac{\vec U_C }{\vec I_C + \vec K \cdot  3 \vec I_0}\label{eq:groupZ13}, 
\end{align}

\begin{eqexpl}[5mm]
    \item{$ 3 \vec I_{0} $}  комплексное  значение  утроенного  тока  нулевой  последовательности  защищаемого объекта (расчетное значение);
    \item{$ \vec K $}  комплексный коэффициент компенсации тока нулевой последовательности защищаемого объекта.
\end{eqexpl}

\medskip

\item 
Коэффициент $\vec K$ задается двумя уставками: \textbf{«KR-1СШ» -- действительная часть коэффициента
компенсации тока 3I0} и \textbf{«KХ-1СШ» -- мнимая часть коэффициента компенсации тока 3I0}.  

\item 
Расчет коэффициентов компенсации тока нулевой последовательности производится на основании
параметров сопротивления смежных элементов сети, подключенных к первой и второй системам шин, по
приведенной ниже формуле:

\begin{align}
\vec K = \frac{1}{3} \cdot \frac{\vec Z_{0 \textsl{ уд}} - \vec Z_{1 \textsl{ уд}}}{\vec Z_{1 \textsl{ уд}}}\label{eq:groupK1},
\end{align}

\begin{eqexpl}[8mm]
\item{$ \vec Z_{0 \textsl{ уд}} $}  комплексное удельное сопротивление сети нулевой последовательности;
\item{$ \vec Z_{1 \textsl{ уд}} $}  комплексное удельное сопротивление сети прямой последовательности.
\end{eqexpl}

\medskip

\item 
Характеристики срабатывания ненаправленного РС для междуфазных контуров задаются независимо
для каждой ступени уставками:
\begin{itemize} 
\item \textbf{«Rср ДЗ-ФФ-1(2..4)»} – активное сопротивление срабатывания РС; 
\item \textbf{«Хср ДЗ-ФФ-1(2..4)»} – реактивное сопротивление срабатывания РС;
\item \textbf{«Ф1 ДЗ-ФФ-1(2..4)»} – угол линии электропередач; 
\end{itemize}

\item 
Характеристики срабатывания ненаправленного РС для однофазных контуров задаются независимо для
каждой ступени уставками:
\begin{itemize} 
\item \textbf{«Rср ДЗ-ФЗ-1(2..4)»} – активное сопротивление срабатывания РС; 
\item \textbf{«Хср ДЗ-ФЗ-1(2..4)»} – реактивное сопротивление срабатывания РС;
\item \textbf{«Ф1 ДЗ-ФЗ-1(2..4)»} – угол линии электропередач; 
\end{itemize}

\item

повреждениях через  переходное  сопротивление  предусмотрена  возможность  отсечения области
характеристики срабатывания,  задаваемой  углом  $φ_4$.  Область  отсекается  отрезком, исходящей  под  углом  $φ_4$,
из точки на верхней части характеристики, соответствующей углу линии электропередачи $φ_1$. Угол $φ_4$
задается уставками \textbf{«Ф4 ДЗ-ФФ-1(3)»} и \textbf{«Ф4 ДЗ-ФЗ-1(3)»}.

\item 
Выполнение функций направленного РС обеспечивается совместным использованием ненаправленного
РС и органов направленности (ОН). Орган направленности представляет собой два отрезка, исходящие из
начала координат и расположенные во втором и четвёртом квадрантах. Вид характеристики  (см. рис. \ref{pict_dz:on}) определяется
углами $φ_2$ и $φ_3$  наклона  этих  отрезков,  отсчитываемых  относительно  оси  $R$. Уставки органов направленности
являются общими для всех ступеней, задаются раздельно для контуров «фаза-фаза» (с помощью уставок \textbf{«Ф2
ОН-ФФ»} и \textbf{«Ф3 ОН-ФФ»}) и «фаза-земля» (с помощью уставок \textbf{«Ф2 ОН-ФЗ»} и \textbf{«Ф3 ОН-ФЗ»}).

\item
Углы наклона в устройстве задаются для ОН в сторону 1СШ (прямонаправленного), а характеристика ОН
в сторону 2СШ (обратнонаправленного) симметрична характеристике прямонаправленного ОН с поворотом на
180 градусов.

\item \textit{«Ненапр»} -- ступень выполнена ненаправленной; 
\item \textit{«Прямо»} -- ступень выполнена прямонаправленной в сторону 1СШ; 
\item \textit{«Обратно»} -- ступень выполнена обратнонаправленной в сторону 2СШ. 
\end{enumerate}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%% БК %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\item\label{sec:secbk} Взаимодействие с блокировкой при качаниях (БК)
\begin{enumerate}

\item
Дистанционная защита контролируется блокировкой при качаниях, предотвращающей ложное
срабатывание ДЗ при качаниях и асинхронном ходе. В устройстве реализовано два способа блокировки:
\begin{itemize}
\item по приращению токов прямой и обратной последовательности;
\item по скорости изменения величины сопротивления dZ/dt.
\end{itemize}

\item
Контроль ступеней ДЗ от блокировки при качаниях вводится программными переключателями
\textbf{«БК ДЗ-ФФ(ФЗ)-1.1(1.2, 2, 3.1, 3.2, 4)»}, имеющими четыре положения:
\begin{itemize}
\item \textit{«Выведено»} -- ступень работает без контроля от БК;
\item \textit{«БК-I-б»} -- ступень пускается от сигнала ввода быстродействующих ступеней;
\item \textit{«БК-I-м»} -- ступень пускается от сигнала ввода медленнодействующих ступеней;
\item \textit{«БК-Z»} -- ступень пускается от сигнала БК по скорости изменения величины сопротивления.
\end{itemize}

\item
Если за время пуска от БК происходит срабатывание РС ступени ДЗ, то разращение от БК
подхватывается и удерживается до пропадания условий срабатывания соответствующей ступени.

\end{enumerate}
