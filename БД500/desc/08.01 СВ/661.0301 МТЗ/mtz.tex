\color{unidarkgreen}{\subsection{Максимальная токовая защита}}
\color{black}

\begin{enumerate}

\item
Максимальная токовая защита с комбинированным пуском по напряжению предназначена для
резервирования основных защит шин и защит отходящих от них присоединений.

\item
На рисунке \ref{pict_mtz:MTZ} приведена функциональная схема МТЗ-1, выполнение функциональной схемы ступени МТЗ-2 аналогичное.

\begin{figure}[H]
\centering
\includegraphics[width=0.8\textwidth,height=0.8\textheight,keepaspectratio]{\fbpath/08.01 СВ/661.0301 МТЗ/img/MTZ.pdf}
\captionof{figure}{Функциональная схема МТЗ-1}\label{pict_mtz:MTZ}
\end{figure}

\item
В составе логики максимальной токовой защиты предусмотрено две ступени МТЗ, ввод в работу которых
осуществляется с помощью программных переключателей \textbf{«МТЗ-1(2)»}. С помощью уставки \textbf{«ИО МТЗ»} имеется
возможность выбрать по фазным или линейным токам (по разности токов) будут работать измерительные
органы МТЗ.

\item
Ток срабатывания ступеней МТЗ задается с помощью уставок \textbf{«Iср МТЗ-1(2)»}, а выдержки времени
срабатывания ступеней регулируются уставками \textbf{«Тср МТЗ-1(2)»}.

\item
Имеется возможность задать различные режимы работы ступеней МТЗ при возникновении
неисправности в цепях напряжения. Вариант действия логики направленных ступеней МТЗ при срабатывании
БНН задается программными переключателями \textbf{«БНН МТЗ-1(2)»}, имеющими три положения:
\begin{itemize}
\item \textit{«Выведено»} -- режим работы ступени не зависит от БНН;
\item \textit{«Вывод напр»} – ступень переводится в ненаправленный режим работы;
\item \textit{«Вывод ступ»} – при срабатывании БНН ступень выводится из работы. Однако, если ступень задана ненаправленной, то она останется в работе независимо от срабатывания БНН. 
\end{itemize}

\item
Для обеспечения несрабатывания МТЗ от бросков намагничивающего тока предусмотрена блокировка
ступеней МТЗ по содержанию второй гармоники в фазном или линейном токе в зависимости от уставки \textbf{«ИО
МТЗ»}. Блокировка основана на контроле отношения действующего значения второй гармоники тока к основной
гармонике. Ввод в работу БНТ МТЗ осуществляется с помощью уставки \textbf{«БНТ МТЗ»}. Ступени МТЗ блокируются
при превышении данного соотношения пороговой величины, заданной уставкой \textbf{«I2г/I1г МТЗ»}. Наличие
функции блокировки от бросков намагничивающего тока задается для каждой ступени отдельно с помощью
программных переключателей \textbf{«БНТ МТЗ-1(2)»}. Для предотвращения излишней блокировки при больших токах
КЗ, сопровождающихся насыщением ТТ, блокировка выводится из действия при превышении тока основной
гармоники выше уставки \textbf{«Iблок БНТ МТЗ»}.

\item
Для повышения чувствительности, предусмотрена возможность пуска ступени МТЗ от
комбинированного пускового органа напряжения первой системы шин (КПОН 1СШ), которая задается
программными переключателями \textbf{«КПОН 1СШ МТЗ-1(2)»} и от комбинированного пускового органа
напряжения второй системы шин (КПОН 2СШ), которая задается программными переключателями \textbf{«КПОН 2СШ МТЗ-1(2)»}.

\item
Направленность МТЗ обеспечивается органами направления мощности выполненными по 90-градусной
схеме с парами токов и напряжений Ia и Ubc, Ib и Uca, Ic и Uab (см. рисунок \ref{pict_mtz:ONM_MTZ}). Направление мощности определяется по
величине фазового угла между током и напряжением отдельно для каждой пары сигналов. Разрешение работы
от органа направленности МТЗ будет происходить от пары сигналов с максимальным током. За положительное
направление векторов принято вращение против часовой стрелки. Углы максимальной чувствительности ОНМ
откладываются от линейных напряжений и задаются уставками \textbf{«Фмч ОНМ в 1СШ»} и \textbf{«Фмч ОНМ в 2СШ»}.
Уставки по углам максимальной чувствительности рекомендуется задавать для ОНМ в 1СШ -- 45º, а для ОНМ
в 2СШ -- 225º. Ширина зоны срабатывания ± 85º от угла максимальной чувствительности. Величина тока работы
ОНМ 0,05$\cdot I_{\textsl{ном}}$, величина напряжения работы ОНМ 0,01$\cdot U_{\textsl{ном}}$.

\begin{figure}[H]
\centering
\includegraphics[width=1\textwidth,height=1\textheight,keepaspectratio]{\fbpath/08.01 СВ/661.0301 МТЗ/img/ONM_MTZ.pdf}
\captionof{figure}{Функциональная схема ОНМ МТЗ}\label{pict_mtz:ONM_MTZ}
\end{figure}

\item
Для выбора режима направленности по мощности предусмотрены программные переключатели
\textbf{«Направл МТЗ-1(2)»}, имеющие три положения:
\begin{itemize}
\item \textit{«Ненапр»} -- ступень выполнена ненаправленной;
\item \textit{«Прямо»} -- ступень выполнена направленной в сторону первой системы шин (1СШ);
\item \textit{«Обратно»} -- ступень выполнена направленной в сторону второй системы шин (2СШ).
\end{itemize}

\item
Оперативный ввод/вывод МТЗ производится с помощью БУ (блоков управления функциями) \textit{«Вывод МТЗ»}. 

\item
В составе логики максимальной токовой защиты предусмотрена логика оперативного ускорения и логика
пуска автоматического ускорения ступеней МТЗ.

\item
Функциональная схема пуска ОУ МТЗ представлена на рисунке \ref{pict_mtz:OA_MTZ}.

\begin{figure}[H]

\includegraphics[width=0.8\textwidth,height=0.8\textheight,keepaspectratio]{\fbpath/08.01 СВ/661.0301 МТЗ/img/OA_MTZ.pdf}

\item
Оперативное ускорение МТЗ предназначено для оперативного ускорения ступени МТЗ при выводе ДЗШ.
Ввод в работу ОУ МТЗ и выбор ускоряемой ступени задается программным переключателем \textbf{«Ступень ОУ
МТЗ»}. Предусмотрена возможность вывода направленности ускоряемой ступени с помощью программного
ключа \textbf{«Направл ОУ МТЗ»}. Действие ускорения осуществляется с регулируемой независимой выдержкой
времени \textbf{«Тср ОУ МТЗ»}. При выводе направленности ускоряемой ступени ее блокировка от БНТ
осуществляется с помощью программного ключа \textbf{«БНТ ОУ МТЗ»}.

\item
Оперативный ввод ОУ МТЗ производится с помощью команды управления \textit{«МТЗ/ОУ МТЗ: Ввод»}.

Функциональная схема пуска АУ МТЗ представлена на рисунке \ref{pict_mtz:AA_MTZ}.

\item
Ввод в работу пуска АУ МТЗ и выбор ускоряемой ступени задается программным переключателем 
\textbf{«Ступень АУ МТЗ»}. Предусмотрена возможность вывода направленности ускоряемой ступени с помощью
программного ключа \textbf{«Направл АУ МТЗ»}. При выводе направленности ускоряемой ступени ее блокировка от
БНТ осуществляется с помощью программного ключа \textbf{«БНТ АУ МТЗ»}.
