\color{uniblue}{\subsection{Защита по скорости изменения частоты (ЗИЧ)}}
\color{black}

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic*, labelsep=4pt, leftmargin=0pt, itemindent=57pt]

\item
Защита по скорости изменения частоты предназначена для фиксации резких изменений частоты в целях предупреждения развивающихся аварий в частотной системе. Данная функция основана на расчете скорости изменения частоты, функция не срабатывает при возникновении переходных нарушений в подаче напряжения.

\item
Основные характеристики функционального блока <<ЗИЧ>>:
\begin{itemize}
    \item погрешность срабатывания ИО скорости изменения частоты должна быть не более 150 мГц;
    \item время срабатывания ИО скорости изменения частоты должно быть не более 200 мс.
\end{itemize}

\item
Функция ЗИЧ выполнена в виде двух независимых ступеней (ЗИЧ 1, ЗИЧ 2), которые представляют собой отдельные функциональные модули с собственными уставками, параметрами конфигурации, внутренними переменными.
\item
Функция содержит в себе ИО, реагирующий на скорость повышения частоты и скорость снижения частоты.
Уставкой SGF2 предоставляется возможность выбора режима работы функции:
\begin{itemize}
    \item если уставка выставлена в положение «по dFdt>», то режим работы по скорости увеличения частоты;
    \item если уставка выставлена в положение «по dFdt<», то режим работы по скорости снижения частоты.
\end{itemize}
\item
Наличие выходного сигнала «ЗИЧ 1: ИО dF/dt» информирует о срабатывании ИО частоты по скорости изменения.
\item
Срабатывание функции происходит после отсчета выдержки времени, задаваемого уставкой T1.
\item
Если до окончания времени таймера выдержки времени на срабатывание скорость изменения частоты увеличивалась или снижалась в зависимости от положения регулируемой уставки SGF2, то активируется таймер задержки на возврат ИО Т2. Таймер задержки на возврат дает возможность таймеру выдержки времени на срабатывание продолжить работу, даже в случае, если скорость изменения частоты кратковременно становилась выше или ниже уставки.
\item
Блокировка функции по напряжению осуществляется снижением линейных напряжений ниже уставки, информируя выходным сигналом <<ЗИЧ: Блок по U>>.

\item
Ввод функции ЗИЧ в работу на этапе параметрирования устройства осуществляется программным переключателем SGF1 <<Ввод\_функции>>. Информация о введенной функции отображается выходным сигналом <<ЗИЧ 1: Ввод>>, <<ЗИЧ 2: Ввод>>.
\item
Функция ЗИЧ может быть выведена из работы оперативно путем активации сигнала <<ОВ ЗИЧ 1>> <<ОВ ЗИЧ 2>>, что характеризуется активным состоянием сигнала <<ЗИЧ 1: Оперативный вывод>>, <<ЗИЧ 2: Оперативный вывод>>.
\item
При активном состоянии входного сигнала <<ЗИЧ 1 на сигн>>, <<ЗИЧ 2 на сигн>> действие соответствующей функции ЗИЧ переводится на сигнал.

\item
Алгоритм работы функции <<ЗИЧ>> выполнен в соответствии с рисунком \ref{zich:img1}. В таблице \ref{zich:tbl1} приведены параметры, необходимые для настройки функции <<ЗИЧ>>.
