\begin{flushleft}
\color{uniblue}{\subsubsection{Общие сведения}}
\color{black}
\nopagebreak
\end{flushleft}

Функциональный блок <<КП>> предназначен:
\begin{itemize}
\item для оперативного управления коммутационными аппаратами; 
\item для формирования сигнала положения коммутационного аппарата для целей АСУ ТП; 
\item для реализации оперативной блокировки управляемых коммутационных аппаратов.
\end{itemize}

В функциональном блоке <<КП>> в составе устройства заложена возможность оперативного управления коммутационными аппаратами в количестве до трех штук: 
\begin{itemize}
\item силовой выключатель (В);
\item заземляющий нож (ЗН);
\item разъединитель (Р).
\end{itemize}

\par
Ввод функционального блока <<КП>> в работу на этапе параметрирования устройства осуществляется программным переключателем SGF1 <<Ввод\_функции>>. Введенное состояние функционального блока соответствует активному состоянию сигнала <<КП: Ввод>>. Функциональный блок <<КП>> может быть выведен из работы оперативно путем активации сигнала <<ОВ КП>>, о чем сигнализирует активное состояние сигнала <<КП: Оперативный вывод>>.

\begin{flushleft}
\needspace{3\baselineskip}
\color{uniblue}{\subsubsection{Управление выключателем (УВ)}}
\color{black}
\nopagebreak
\end{flushleft}

\par
Ввод функции <<УВ>> в работу на этапе параметрирования устройства осуществляется программным переключателем SGF1 <<Ввод\_функции>>. Введенное состояние функции соответствует активному состоянию сигнала <<УВ: Ввод>>.
Функция <<УВ>> формирует команды на отключение и включение выключателя при оперативном управлении.

\par
Команда \emph{оперативного отключения} <<УВ: Отключить>> формируется в следующих случаях:
\begin{itemize}
	\item при появлении команды на оперативное отключение выключателя (<<Отключить В~от~ПУ>> или <<Откл. В~ИЧМ>>) и выбранным управлением по месту (сигнал <<Местное>> находится в активном состоянии);
	\item при появлении команды на оперативное отключение выключателя (<<Отключить В~от~ТУ>> или <<Откл. В~АСУ>>) и выбранным дистанционным управлением (сигнал <<Дистанционное>> находится в активном состоянии).
\end{itemize}
Прохождение команды на отключение блокируется при наличии следующих сигналов:
\begin{itemize}
	\item запрет отключения от функции контроля силового выключателя <<КСВ: Блокировка откл>>;
	\item отключенное состояние силового выключателя <<В: Отключен>>;
	\item превышение времени переключения силового выключателя <<УВ: Прев. времени~пер.>>;
	\item местное управление силовым выключателем (положение переключателя <<М/Д>> в приводе выключателя) <<В:~Ключ М/Д привода>>.
\end{itemize}

\par
Команда \emph{оперативного включения} <<УВ: Включить>> формируется в следующих случаях:
\begin{itemize}
	\item при появлении команды на оперативное включение выключателя (<<Включить В~от~ПУ>> или <<Вкл. В~ИЧМ>>) и выбранным управлением по месту (сигнал <<Местное>> находится в активном состоянии);
	\item при появлении команды на оперативное включение выключателя (<<Включить В~от~ТУ>> или <<Вкл. В~АСУ>>) и выбранным дистанционным управлением (сигнал <<Дистанционное>> находится в активном состоянии).
\end{itemize}
Прохождение команды на включение блокируется при наличии следующих сигналов:
\begin{itemize}
	\item запрет включения от функции контроля силового выключателя <<КСВ: Блокировка вкл>>;
	\item включенное состояние силового выключателя <<В:~Включен>>;
	\item превышение времени переключения силового выключателя <<УВ: Прев. времени~пер.>>;
	\item местное управление силовым выключателем (положение переключателя <<М/Д>> в приводе выключателя) <<В:~Ключ М/Д привода>>;
	\item появление сигнала аварийного отключения силового выключателя <<КСВ: В аварийно отключен>> (прохождение сигнала определяется состоянием программного переключателя SGF2 <<Бл\_вкл\_от\_авар\_откл>>).
\end{itemize}

\par
При наличии сигналов <<УВ: Включить>> и <<УВ: Отключить>> длительностью больше, чем время уставки <<T1>> формируется сигнал превышения допустимого времени переключения -- <<УВ: Прев. времени пер.>>. Активное состояние операции включения или отключения сигнализируется выходным сигналом <<УВ: Идет переключение>>.

\par
Логика функции <<УВ>> формирует сигналы состояния выключателя <<УВ: Отключено>>, <<УВ: Включено>>, <<УВ: Не определено>> и <<УВ: Неисправность>>, при этом сигналы <<УВ: Неисправность>> и <<УВ: Не определено>> выдаются с выдержкой времени, задаваемой уставкой Т2 <<Тблк>>.

\color{uniblue}{\subsubsection{Оперативная блокировка ЗН (ОБР ЗН)}}
\color{black}
\nopagebreak
\end{flushleft}

\par
Ввод <<ОБР ЗН>> в работу на этапе параметрирования устройства осуществляется общим программным переключателем SG1 <<ОБР\_КА>> (см. таблицу \ref{kp:tbl_gen}).

\par
Принудительное деблокирование управления заземляющего разъединителя трансформатора стороны ВН от оперативной блокировки осуществляется активацией входного сигнала <<Программ. деблок. ЗН>>.
\par
Разрешение на отключение заземляющего разъединителя выдается без дополнительных условий.
\par
Разрешение на включение заземляющего разъединителя выдается при выполнении необходимых условий:
\begin{itemize}
	\item разъединитель трансформатора стороны ВН отключен; 
	\item разъединитель трансформатора стороны НН1 отключен либо выкатной элемент выключателя НН1 трансформатора в выкаченном состоянии (контроль сигнала определяется состоянием программного переключателя SGF1 <<Контр\_КА3>>); 
	\item разъединитель трансформатора стороны НН2 отключен либо выкатной элемент выключателя НН2 трансформатора в выкаченном состоянии (контроль сигнала определяется состоянием программного переключателя SGF2 <<Контр\_КА4>>).
\end{itemize}

\par
Алгоритм работы <<ОБР ЗН>> выполнен в соответствии с рисунком \ref{kp:img_obrzn}. В таблице \ref{kp:tbl_obrzn} приведены параметры, необходимые для настройки функции <<ОБР ЗН>>.
