\color{uniblue}{\subsection{Контроль отсутствия напряжения (КОН)}}
\color{black}

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic*, labelsep=4pt, leftmargin=0pt, itemindent=57pt]

\item
Функция КОН контролирует отсутствие напряжения на электрооборудовании.

\item
Контроль отсутствия напряжения на электрооборудовании срабатывает без выдержки времени при одновременном снижении всех линейных напряжений секции ниже уставки. Блокировка пусковых условий функции формируется при наличии неисправности цепей напряжения (БНН).

\item
Ввод функции в работу на этапе параметрирования устройства осуществляется программным переключателем SGF1 <<Ввод\_функции>>. Информация о введенной функции отображается выходным сигналом <<КОН: Ввод>>.

\item
Функция <<КОН>> может быть выведена из работы оперативно путем активации сигнала <<ОВ КОН>>, что характеризуется активным состоянием сигнала <<КОН: Оперативный вывод>> на выходе функции. 
\item
Алгоритм работы функции <<КОН>> выполнен в соответствии с рисунком \ref{kon:img1}. В таблице \ref{kon:tbl1} приведены параметры, необходимые для настройки функции <<КОН>>.
