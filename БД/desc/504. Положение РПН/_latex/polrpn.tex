\item Диапазон возможных положений привода РПН – 1…40.
\item Текущее положение РПН
    \begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]
        \item В устройстве предусмотрено три варианта контроля текущего положении переключателя РПН:
            \begin{itemize}
                \item внутренний счетчик положений (только для импульсного режима управляющих команд);
                \item внешний датчик (логометр) с выходом токовая петля 4(0)-20 мА;
                \item GOOSE сообщение.
            \end{itemize}
        \item
        Выбор источника информации о текущем положении осуществляется программным переключателем SGF1 (см. рисунок 2.13).
        \item Если в качестве источника информации о текущем положении РПН выбран внутренний счетчик, необходимо выполнить определенные настройки устройства. Для этого необходимо задать следующие параметры:
            \begin{itemize}
                \item значение текущего положения;
                \item направление счета (прямое/обратное).
            \end{itemize}
        \item 
        В аппаратном обеспечении устройства предусмотрены два входа типа токовая петля 4(0)-20 мА. К первому из них может быть подключен внешний логометр. Назначение второго входа - подключение токовой петли логометра параллельно работающего трансформатора в соответствующем случае.
        \item При выборе токовой петли в качестве источника информации о положении РПН для его настройки необходимо задать следующие параметры:
            \begin{itemize}
                \item значение тока в интерфейсе токовой петли, соответствующее начальному положению;
                \item значение тока в интерфейсе токовой петли, соответствующее конечному положению.
            \end{itemize}
        \end{enumerate}
\item Крайние положения РПН, мертвые положения
    \begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]
        \item Для некоторых положений из диапазона ступеней используются следующие термины:
            \begin{itemize}
                \item	крайнее верхнее положение;
                \item	крайнее нижнее положение;
                \item	допустимое верхнее положение;
                \item	допустимое нижнее положение;
                \item	мертвое положение.

            \end{itemize}
        \item
        Как было отмечено выше, устройство получает информацию от концевых выключателей привода через дискретные входы или GOOSE сообщение. При достижении приводом крайних положений блокируются команды управления в соответствующем направлении, чтобы не формировался сигнал <<Привод не пошел>>.
        \item
        В устройстве имеется возможность ограничить диапазон регулирования в автоматическом режиме. Это возможно заданием параметров допустимого верхнего и нижнего положений, отличных от крайних положений привода.
        \item
        Мертвое (или пустое) положение - положение привода, при котором не происходит изменения коэффициента трансформации трансформатора. Если конструкция привода предусматривает наличие мертвых положений, привод проходит данные положения автоматически без каких-либо команд со стороны устройства. Уставками устройства необходимо задать положения, которые являются мертвыми, чтобы не формировался сигнал <<Привод побежал>>.
    \end{enumerate}
