%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%% Формирование команд на привод %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\item\label{form} Формирование команд на привод

\begin{enumerate}

\item В зависимости от выбранного режима работы устройство может формировать три вида команд управления на привод:
\begin{itemize}
    \item оперативные;
    \item автоматические;
    \item от устройства регулирования трансформатора, включенного на параллельную работу.
\end{itemize}

\item\label{vydacha}
Оперативные команды управления имеют взаимную блокировку команд <<Прибавить>> и <<Убавить>>. Таймер <<t3>> (см. рисунок \ref{kntr:img1}) ограничивает длительность команды управления, в импульсном режиме сбрасывает команду после появления сигнала <<Идет переключение>>. В непрерывном режиме управления уставка данного таймера должна быть достаточной, чтобы привод гарантировано начал переключение.

\end{enumerate}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%% Контроль привода в процессе переключения %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\item\label{kntr} Контроль привода в процессе переключения

\begin{enumerate}

\item Функциональная схема логики контроля привода приведена на рисунке \ref{kntr:img2}.

\item Кроме таймера <<t3>> в логике устройства предусмотрен ряд таймеров, используемых для управления приводом и для его диагностики в процессе переключения в случае импульсного режима выдачи команд:

\begin{itemize}
\item таймер <<t1>> (время реакции привода на команду управления) -- при отсутствии переключения в течение выдержки времени таймера <<t1>> формируется сигнал <<ПМ не пошел>>;
\item таймер <<t2>> (максимальная продолжительность переключения) -- при удержании сигнала <<Идет переключение>> в течение выдержки времени таймера <<t2>> устройство формирует сигнал <<ПМ застрял>>.
\end{itemize}

\item При отсутствии команд управления и появлении сигнала <<Идет переключение>> устройство формирует сигнал <<ПМ побежал>>. При возникновении данной ситуации, устройство ожидает завершение переключения и формирует сигнал <<Отключить автомат РПН>>.

\item
Программный переключатель SGF2 определяет время воздействия на дистанционный расцепитель автоматического выключателя привода:
\begin{itemize}
\item непрерывном;
\item в течение 1 с.
\end{itemize}

\item Выбор режима выдачи управляющих команд (Импульсный/Непрерывный) осуществляется программным переключателем SGF1.

\end{enumerate}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%% Формирование команд автоматического управления %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\item\label{avt} Формирование команд автоматического управления

\begin{enumerate}

\item
В режиме автоматического регулирования устройство непрерывно отслеживает уровень напряжения на регулируемой секции (см. раздел \ref{avtreg}). При выходе напряжения за пределы <<Зоны нечувствительности>> устройство с определенными выдержками времени формирует сигналы управления приводом (см. рисунок \ref{kntr:img3}). 
\item
Используются следующие выдержки времени:
\begin{itemize}
    \item задержка на выдачу первой автоматической команды (уставка таймера <<T1>>) <<Прибавить>> или <<Убавить>> при выходе значения напряжения регулируемой секции за пределы зоны нечувствительности;
    \item задержка на выдачу повторной автоматической команды (уставка таймера <<T2>>) <<Прибавить>> или <<Убавить>>; вторая и все последующие команды выдаются с данной задержкой до возврата напряжения в пределы зоны нечувствительности;
    \item задержка на выдачу команды «Убавить» (уставка таймера <<T3>>) при значительном увеличении напряжения. При перенапряжении на регулируемой секции первая и все последующие автоматические команды <<Убавить>> выдаются с данной выдержкой времени.  
\end{itemize}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%% Счетчик переключений и контроль выработанного ресурса %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\item\label{resurs} Счетчик переключений и контроль выработанного ресурса

\begin{enumerate}

\item
В устройстве предусмотрен контроль выработанного ресурса. При каждом переключении значение счетчика переключений сравнивается с уставкой <<Максимальное количество операций переключения>>. При превышении уставки формируется сигнал превышения максимального количества переключений. Имеется возможность сбросить значение счетчика переключений через виртуальный ключ. Также имеется возможность задать уставкой начальное значение счетчика.

\item
Алгоритм работы счетчика переключений и контроля выработанного ресурса выполнен в соответствии с рисунком \ref{kntr:img4}.
