\item Общие сведения

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
КП предназначен:
\begin{itemize}
\item для оперативного управления коммутационными аппаратами; 
\item для формирования сигнала положения коммутационного аппарата для целей АСУ ТП; 
\item для реализации оперативной блокировки управляемых коммутационных аппаратов.
\end{itemize}

\item
В устройстве контроллер присоединения представлен функциональным блоком «КП». В функциональном блоке заложена возможность оперативного управления следующими коммутационными аппаратами:
\begin{itemize}
	\item силовой выключатель (В);
	\item заземляющий нож (ЗН);
	\item выкатной элемент 1 (ВЭ1);
	\item выкатной элемент 2 (ВЭ2).
\end{itemize}

\item
При выполнении коммутационной операции В, ЗН, или ВЭ информация об этом процессе будет отображаться общим выходным сигналом «КП: Идет переключение». Функциональная схема формирования общего сигнала представлена на рисунке \ref{kp:img_perkl}.

\item
Ввод функционального блока в работу на этапе параметрирования устройства осуществляется программным переключателем SGF1 «Ввод\_функции». Введенное состояние функционального блока соответствует активному состоянию сигнала «КП: Ввод».

\item
Функциональный блок может быть выведен из работы оперативно путем активации сигнала «ОВ КП», о чем сигнализирует активное состояние сигнала «КП: Оперативный вывод».

\item Управление выключателем (УВ)

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
В функциональном блоке «КП» логика управления выключателем представлена функцией «УВ». Функция формирует команды на отключение и включение выключателя при оперативном управлении.

\item
Местное управление коммутационным аппаратом осуществляется только посредством кнопок \tikz[baseline={(0,-0.00ex)}]{\draw[line width=1.6pt] (0,0) rectangle (1em,1em);\node[anchor=center] at (0.5em,0.5em) {\textbf{I}};}~–~«Включить» и \tikz[baseline={(0,-0.00ex)}]{\draw[line width=1.6pt] (0,0) rectangle (1em,1em);\node[anchor=center] at (0.5em,0.5em) {\textbf{O}};}~–~«Отключить». При этом необходимо перевести устройство в режим «Местное» с помощью заданной функциональной кнопки. В данном случае управление по локальной сети и с помощью выносных кнопок или ключей будет невозможно.
\item
Дистанционное управление может реализоваться через дискретные входы, которые сконфигурированы как «Включить В от ТУ» и «Отключить В от ТУ», а также по локальной сети. В дистанционном режиме управления команды по локальной сети предусмотрены постоянно.
\item
Управление выключателем также осуществляется с помощью пульта управления (ПУ), который предназначен для формирования команд управления выключателем путем автоматической подачи на катушки электромагнитов электрического напряжения. Управление с ПУ может реализоваться через дискретные входы, которые сконфигурированы как «Включить В от ПУ» и «Отключить В от ПУ».

\item
Команда оперативного отключения «УВ: Отключить» формируется в следующих случаях:
\begin{itemize}
	\item при появлении команды на оперативное отключение выключателя («Отключить В~от~ПУ» или «Откл. В~ИЧМ») и выбранным управлением по месту (сигнал «Местное» находится в активном состоянии);
	\item при появлении команды на оперативное отключение выключателя («Отключить В~от~ТУ» или «Откл. В~АСУ») и выбранным дистанционным управлением (сигнал «Дистанционное» находится в активном состоянии).
\end{itemize}
\item
Прохождение команды на отключение блокируется при наличии следующих сигналов:
\begin{itemize}
	\item запрет отключения от функции контроля силового выключателя «КСВ: Блокировка откл»;
	\item отключенное положение силового выключателя «В отключен (б/к)» (с контролем сигнала «В включен~(б/к)»);
	\item превышение времени переключения силового выключателя «УВ: Прев. времени~пер.»;
	\item местное управление силовым выключателем (положение переключателя «М/Д» в приводе выключателя) «Ключ М/Д привода В».
\end{itemize}

\item
В устройстве применяется режим включения выключателя с контролем синхронизма, который контролируется уставкой SGF2 «Контроль\_синхр». Если уставка SGF2 введена в работу, то при наличии разрешающих условий для включения выключателя и активного сигнала разрешения оперативного включения из функции КС «Разреш.опер.вкл.В» формируется команда включения с контролем синхронизма.

\item
Команда оперативного включения «УВ: Включить» без контроля синхронизма формируется в следующих случаях:
\begin{itemize}
	\item при появлении команды на оперативное включение выключателя («Включить В~от~ПУ» или «Вкл. В~ИЧМ») и выбранным управлением по месту (сигнал «Местное» находится в активном состоянии);
	\item при появлении команды на оперативное включение выключателя («Включить В~от~ТУ» или «Вкл. В~АСУ») и выбранным дистанционным управлением (сигнал «Дистанционное» находится в активном состоянии).
\end{itemize}

\item
Прохождение команды на включение блокируется при наличии следующих сигналов:
\begin{itemize}
	\item запрет включения от функции контроля силового выключателя «КСВ: Блокировка вкл»;
	\item включенное положение силового выключателя «В~включен (б/к)» (с контролем сигнала «В~отключен~(б/к)»);
	\item превышение времени переключения силового выключателя «УВ: Прев. времени~пер.»;
	\item местное управление силовым выключателем (положение переключателя «М/Д» в приводе выключателя) «Ключ М/Д привода В»;
	\item появление сигнала аварийного отключения силового выключателя «КСВ: В аварийно отключен» (прохождение сигнала определяется состоянием программного переключателя SGF3 «Бл\_вкл\_от\_авар\_откл»).
\end{itemize}

\item  
При наличии введенной уставки включения выключателя с контролем синхронизма SGF2 и превышение времени регулируемой уставки «T3» формируется выходной сигнал задержки включения для сброса команды.

\item
При наличии сигналов «УВ: Включить» и «УВ: Отключить» длительностью больше, чем время уставки «T1» формируется сигнал превышения допустимого времени переключения -- «УВ: Прев. времени пер.». Активное состояние операции включения или отключения сигнализируется выходным сигналом «УВ: Идет переключение».

\item
Логика функции формирует сигналы состояния выключателя «УВ: Отключено», «УВ: Включено», «УВ: Не определено» и «УВ: Неисправность», при этом сигналы «УВ: Неисправность» и «УВ: Не определено» выдаются с выдержкой времени, задаваемой уставкой Т2 «Тблк».

\item
Ввод функции в работу на этапе параметрирования устройства осуществляется программным переключателем SGF1 «Ввод\_функции». Информация о введенной функции отображается выходным сигналом «УВ: Ввод».

\item

\item Управление заземляющим ножом (УЗН)

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
В функциональном блоке «КП» логика управления заземляющим ножом представлена функцией «УЗН». Функция формирует команды на отключение и включение зазмляющего ножа при оперативном управлении.

\item
Команда оперативного отключения «УЗН: Отключить» формируется в следующих случаях:
\begin{itemize}
	\item при появлении команды на оперативное отключение заземляющего ножа («Откл. ЗН ИЧМ»), выбранным управлением по месту (сигнал «Местное» находится в активном состоянии) и наличием разрешающего сигнала от схемы оперативной блокировки «ОБР ЗН: Разрешить управ.»;
	\item при появлении команды на оперативное отключение заземляющего ножа («Откл. ЗН АСУ»), выбранным дистанционным управлением (сигнал «Дистанционное» находится в активном состоянии) и наличием разрешающего сигнала от схемы оперативной блокировки «ОБР ЗН: Разрешить управ.».
\end{itemize}

\item
Прохождение команды на отключение блокируется при наличии следующих сигналов:
\begin{itemize}
	\item отключенное положение заземляющего ножа «ЗН отключен (б/к)» (с контролем сигнала «ЗН включен~(б/к)»);
	\item превышение времени переключения заземляющего ножа «УЗН: Прев. времени~пер.».
\end{itemize}

\item
Команда оперативного включения «УЗН: Включить» формируется в следующих случаях:
\begin{itemize}
	\item при появлении команды на оперативное включение выключателя («Вкл. ЗН ИЧМ»), выбранным управлением по месту (сигнал «Местное» находится в активном состоянии) и наличием разрешающего сигнала от схемы оперативной блокировки «ОБР ЗН: Разрешить управ.»;
	\item при появлении команды на оперативное включение выключателя («Вкл. ЗН АСУ»), выбранным дистанционным управлением (сигнал «Дистанционное» находится в активном состоянии) и наличием разрешающего сигнала от схемы оперативной блокировки «ОБР ЗН: Разрешить управ.».
\end{itemize}

\item
Прохождение команды на включение блокируется при наличии следующих сигналов:
\begin{itemize}
	\item включенное положение заземляющего ножа «ЗН~включен (б/к)» (с контролем сигнала «ЗН~отключен~(б/к)»);
	\item превышение времени переключения заземляющего ножа «УЗН: Прев. времени~пер.».
\end{itemize}

\item
При наличии сигналов «УЗН: Включить» и «УЗН: Отключить» длительностью больше, чем время уставки «T1» формируется сигнал превышения допустимого времени переключения -- «УЗН: Прев. времени пер.». Активное состояние операции включения или отключения сигнализируется выходным сигналом «УЗН: Идет переключение».

\item
Логика функции формирует сигналы состояния выключателя «УЗН: Отключено», «УЗН: Включено», «УЗН: Не определено» и «УЗН: Неисправность», при этом сигналы «УЗН: Неисправность» и «УЗН: Не определено» выдаются с выдержкой времени, задаваемой уставкой Т2 «Тблк».

\item

\item Управление выкатным элементом (УВЭ)

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]


\item
В функциональном блоке «КП» логика управления выкатными элементами представлена функциями «УВЭ1», «УВЭ2». Функции формируют команды вкатить и выкатить выкатные элементы ячеек ввода и секционного разъединителя при оперативном управлении.

\item
Команда операции выкатить ВЭ «УВЭ1(2): Выкатить» формируется в следующих случаях:
\begin{itemize}
	\item при появлении команды выкатить от местного управления («Выкат. ВЭ1(2) ИЧМ»), выбранным управлением по месту (сигнал «Местное» находится в активном состоянии) и наличием разрешающего сигнала от схемы оперативной блокировки «ОБР ВЭ1(2): Разрешить управ.»;
	\item при появлении команды выкатить от дистанционного управления («Выкат. ВЭ1(2) АСУ»), выбранным дистанционным управлением (сигнал «Дистанционное» находится в активном состоянии) и наличием разрешающего сигнала от схемы оперативной блокировки «ОБР ВЭ1(2): Разрешить управ.».
\end{itemize}

\item
Прохождение команды выкатить ВЭ1(2) блокируется при наличии следующих сигналов:
\begin{itemize}
	\item контрольное положение ВЭ1(2);
	\item превышение времени операции вкатить/выкатить ВЭ1(2) «УВЭ1(2): Прев. времени~пер.».
\end{itemize}

\item
Команда операции вкатить ВЭ1(2) «УВЭ1(2): Вкатить» формируется в следующих случаях:
\begin{itemize}
	\item при появлении команды вкатить от местного управления («Вкат. ВЭ1(2) ИЧМ»), выбранным управлением по месту (сигнал «Местное» находится в активном состоянии) и наличием разрешающего сигнала от схемы оперативной блокировки «ОБР ВЭ1(2): Разрешить управ.»;
	\item при появлении команды вкатить от дистанционного управления («Вкат. ВЭ1(2) АСУ»), выбранным дистанционным управлением (сигнал «Дистанционное» находится в активном состоянии) и наличием разрешающего сигнала от схемы оперативной блокировки «ОБР ВЭ1(2): Разрешить управ.».
\end{itemize}

\item
Прохождение команды вкатить ВЭ1(2) блокируется при наличии следующих сигналов:
\begin{itemize}
	\item рабочее положение ВЭ1(2);
	\item превышение времени операции вкатить/выкатить ВЭ «УВЭ1(2): Прев. времени~пер.».
\end{itemize}

\item
При наличии сигналов «УВЭ1(2): Вкатить» и «УВЭ1(2): Выкатить» длительностью больше, чем время уставки «T1» формируется сигнал превышения допустимого времени операции -- «УВЭ1(2): Прев. времени пер.». Активное состояние операции включения или отключения сигнализируется выходным сигналом «УВЭ: Идет переключение».

\item
Логика функций формирует сигналы состояния выключателя «УВЭ1(2): Выкачен», «УВЭ1(2): Вкачен», «УВЭ1(2): Не определено» и «УВЭ1(2): Неисправность», при этом сигналы «УВЭ1(2): Неисправность» и «УВЭ1(2): Не определено» выдаются с выдержкой времени, задаваемой уставкой Т2 «Тблк».

\item
Ввод функций в работу на этапе параметрирования устройства осуществляется своим программным переключателем SGF1 «Ввод\_функции». Информация о введенной функции отображается выходным сигналом «УВЭ1(2): Ввод».

\item Оперативная блокировка выключателя (ОБР В)

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

Условием ввода в работу разрешения управления выключателем является наличие входного сигнала «УВ: Ввод». Контроль условий блокировки управления выключателем осуществляется с помощью уставки SGF1. 	\item для управления выключателем в контрольном (ремонтном) положении необходимо активное состояние сигнала «ВЭ: Выкачен»;
	\item для управления выключателем в рабочем положении (активное состояние сигнала «ВЭ1: Вкачен») необходимо одновременное наличие следующих сигналов: «ЗН: Отключен», «КА1 Отключен», «КА2 Отключен», если введен контроль данных сигналов соответствующими программными переключателями, при этом есть возможность дополнительного контроля положения тележки секционного разъединителя уставкой программного переключателя SGF5 «Контр\_от\_ВЭ2»;
	\item для управления выключателем в рабочем положении и введенной уставкой «Предусмотрено» программного переключателя SGF5 «Контр\_от\_ВЭ2» разрешающий сигнал на управление выключателем дополнительно подтверждается либо выкаченным состоянием ВЭ секционного разъединителя (сигнал «ВЭ2: Выкачен») либо, в случае вкаченного состояния ВЭ секционного разъединителя (сигнал «ВЭ2: Вкачен»), одновременным наличием следующих сигналов: «КА3 Отключен», «КА4 Отключен», если введен контроль данных сигналов соответствующими программными переключателями.
\end{itemize}
\item
Внешние дискретные входы назначаются в проекте непосредственно под схему объекта. Блокировка включения выключателя выполняется при несоблюдении какого-либо из условий, предусмотренных алгоритмом логики «ОБР В».

\item Оперативная блокировка выкатного элемента 2 (ОБР ВЭ2)

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
В функциональном блоке «КП» логика оперативной блокировки выкатного элемента 2 представлена функцией «ОБР ВЭ2». Условие ввода в работу разрешения управления ВЭ2 является наличие входного сигнала «УВЭ2: Ввод». Контроль условий блокировки управления ВЭ2 осуществляется с помощью уставки SG1. Если уставка SG1 (см. таблицу \ref{kp:tbl_gen}) выставлена в положение «Не предусмотрено», то управление ВЭ2 осуществляется без учета всех блокировок.

\item
Принудительное деблокирование управления выкатным элементом от оперативной блокировки осуществляется активацией входного сигнала от ключа «Программ. деблок. ВЭ2».

\item
Разрешение управления ВЭ2 формируется при выполнении необходимых условий:
\begin{itemize}
	\item отсутствие процесса переключения коммутационных аппаратов (сигнал «КП: Идет переключение»);
	\item при вкаченном положении ВЭ2 (активное состояние сигнала «ВЭ2: Вкачен») необходимо выполнение любого из условий: отключен выключатель или выкачен ВЭ1 (сигналы «ВЭ1: Выкачен», «В: Отключен»);
	\item в случае выкаченного положения ВЭ2 необходимо выполнение следующих условий: отключен выключатель или выкачен ВЭ1 (сигналы «ВЭ1: Выкачен», «В: Отключен»), отключен заземляющий нож (сигнал «ЗН: Отключен») и наличие сигнала «КА5 Отключен» -- при введенном программном переключателе SGF1.
\end{itemize}

\item
Внешние дискретные входы назначаются в проекте непосредственно под схему объекта. Блокировка управления ВЭ2 выполняется при несоблюдении какого-либо из условий, предусмотренных алгоритмом логики «ОБР ВЭ2».
