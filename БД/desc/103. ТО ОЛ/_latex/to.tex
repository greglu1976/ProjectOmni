\color{uniblue}{\subsection{Токовая отсечка (ТО)}}
\color{black}

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic*, labelsep=4pt, leftmargin=0pt, itemindent=57pt]

\item
Токовая отсечка предназначена  для  максимально  быстрой  ликвидации  коротких  замыканий, возникающих в начале рабочей зоны.
\item
Функция <<ТО>> контролирует повышение любого фазного тока (\textsl{IA мгн, IB мгн, IC мгн}) выше заданной уставки, при превышении заданной уставки по току через выдержку времени таймера T1 (уставка <<Тср>>) выдается сигнал на отключение трансформатора. При активном состоянии входного сигнала <<ТО на сигн>> действие токовой отсечки переводится на сигнал.
\item
Ввод функции в работу на этапе параметрирования устройства осуществляется программным переключателем SGF1 <<Ввод\_функции>>. Информация о введенной функции отображается выходным сигналом <<ТО: Ввод>>.
\item
Функция <<ТО>> может быть выведена из работы оперативно путем активации сигнала <<ОВ ТО>>, что характеризуется активным состоянием сигнала <<ТО: Оперативный вывод>> на выходе функции. 
\item
Алгоритм работы функции <<ТО>> выполнен в соответствии с рисунком \ref{to:img1}. В таблице \ref{to:tbl1} приведены параметры, необходимые для настройки функции <<ТО>>.
