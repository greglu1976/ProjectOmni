\item Общие сведения

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
Авматическое ограничение снижения частоты (АОСЧ) предназначено для предотвращения недопустимого по условиям устойчивой работы генерирующего оборудования и энергопринимающих установок потребителей электрической энергии снижения частоты и полного погашения энергосистемы или её части при возникновении дефицита активной мощности, в том числе при аварийном выделении энергосистемы или её части на изолированную работу. АОСЧ предотвращает образование лавины частоты и/или лавины напряжения в энергосистеме путем отключения части нагрузки. Отключенная нагрузка впоследствии может быть вновь включена устройством автоматически.

 \item
В устройстве автоматика ограничения снижения частоты представлена функциональным блоком «АОСЧ». Функциональный блок включает в себя следующие функции:
\begin{itemize}
    \item автоматическая частотная разгрузка (АЧР) в составе:
    \begin{enumerate}[label=\arabic*)]  
    \item блокировка по скорости снижения частоты (БССЧ), см. п.\ref{punktbssch};
    \item контроль напряжения и частоты смежной секции шин (КССШ), см. п.\ref{punktksssh};
    \item подсистемы АЧР-1 и АЧР-2 (АЧР1, АЧР2), см. п.\ref{punktachr};
    \item специальная очередь АЧР (САЧР), см. п.\ref{punktsachr};
    \item сборка сигналов срабатывания функций в составе АЧР, см. п.\ref{punktssachr};
    \end{enumerate} 
    \item частотное автоматическое повторное включение (ЧАПВ), см. п.\ref{punktchapv};
    \item сборка сигналов срабатывания ступеней в составе ЧАПВ, см. п.\ref{punktsschapv}.   
\end{itemize}

\item
Основные характеристики функционального блока:
\begin{itemize}
    \item основная погрешность срабатывания ИО частоты не более 20 мГц;
    \item основная погрешность возврата ИО частоты не более 20 мГц;
    \item основная погрешность срабатывания ИО скорости изменения частоты должна быть не более 150 мГц;
    \item основная погрешность ИО частоты в рабочем диапазоне при напряжении входного сигнала 100 В не более 10 мГц;
    \item время срабатывания и возврата ИО частоты не более 60 мс;
    \item время срабатывания ИО скорости изменения частоты должно быть не более 200 мс.
\end{itemize}

\item
Функциональный блок может быть полностью выведен из работы оперативно путем активации сигнала «ОВ АОСЧ».

\end{enumerate}

\item Блокировка по скорости снижения частоты (БССЧ) \label{punktbssch}

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
В устройстве предусмотрена блокировка для предотвращения срабатывания АЧР при выбеге электродвигателей. Блокировка срабатывания при выбеге электродвигателей будет сохраняться, в том числе и после снижения частоты ниже 45,0 Гц.

\item 
В устройстве блокировка по скорости снижения частоты представлена функцией «БССЧ». Ввод функции в работу на этапе параметрирования устройства осуществляется своим программным переключателем SGF1 «Ввод\_функции». Информация о введенной функции отображается выходным сигналом «БССЧ: Ввод».

\item
Функция может быть выведена из работы оперативно путем активации сигнала «ОВ АЧР» (совместно со всеми функциями устройства АЧР).

\item
Срабатывание функции происходит при превышении скорости снижения частоты уставки. Уставкой SGF2 «Усл\_БССЧ» контролируется условие возврата ИО БССЧ, если уставка SGF2 выставлена в положение «Возврат F», то возврат органа происходит при сбросе триггера, подхватывающего блокировку, при превышении уставки частоты, если уставка SGF2 выставлена в положение «Возврат dF/dt», то возврат органа происходит при снижении скорости изменения частоты.

\item
Пуск блокировки осуществляется после срабатывания ИО по скорости снижения частоты выше уставки, информируя выходными сигналами «БССЧ: ИО dFосн/dt» и «БССЧ: Пуск». Срабатывание функции происходит после отсчета выдержки времени, задаваемого уставкой T1.

\item Контроль напряжения и частоты смежной секции шин (КССШ) \label{punktksssh}

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
КССШ контролирует напряжение смежной секции и частоту для пуска АЧР. В устройстве контроль напряжения и частоты смежной секции шин представлен функцией «КССШ». Ввод функции в работу на этапе параметрирования устройства осуществляется своим программным переключателем SGF1 «Ввод\_функции». Информация о введенной функции отображается выходным сигналом «КССШ: Ввод».

\item
Функция может быть выведена из работы оперативно путем активации сигнала «ОВ АЧР» (совместно со всеми функциями устройства АЧР).

\item
 Срабатывание функции осуществляется при одновременном выполнении следующих условий:
\begin{itemize}
    \item частота смежной секции ниже уставки;
    \item все три линейные напряжения смежной секции выше уставки.
\end{itemize}

\item
Наличие выходного сигнала «КССШ: ИО Uсм>» соответствует наличию номинального напряжения на смежной секции. В этом режиме при снижении частоты и наличии номинального напряжения на смежной секции собираются условия для разрешения АЧР, формируя выходным сигналом «КССШ: Срабатывание». Срабатывание функции происходит без выдержки времени.

\item
При отсутствии напряжения на соседней секции, если уставка SGF2 «Разреш\_АЧР» установлена в положение «Предусмотрено», функция формирует выходной сигнал «КССШ: Срабатывание» без контроля частоты на смежной секции.

\item Очереди АЧР-1 и АЧР-2 (АЧР1, АЧР2) \label{punktachr}

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
Очереди АЧР-1, АЧР-2 включают следующие функции:
\begin{itemize}
    \item очередь АЧР-1 с четырьмя ступенями (АЧР1-1, АЧР1-2, АЧР1-3, АЧР1-4);
    \item очередь АЧР-2 с четырьмя ступенями (АЧР2-1, АЧР2-2, АЧР2-3, АЧР2-4).
\end{itemize}
\item
Ввод ступени (m) очереди (n) АЧР в работу на этапе параметрирования устройства осуществляется своим программным переключателем SGF1 «Ввод\_функции». Информация о введенной ступени отображается выходным сигналом для каждой ступени «АЧР(n) (m): Ввод», здесь и далее в этом подразделе: (n) -- номер очереди, $n\in\{1,2\}$, (m) -- номер ступени, $m\in\{1,2,3,4\}$.

\item
Для срабатывания каждой ступени очереди АЧР1, АЧР2 необходимо одновременное наличие следующих условий:
\begin{itemize}
    \item ступень введена в работу;
    \item снижение частоты ниже уставки (наличие выходного сигнала «АЧР(n) (m): ИО F<»);
    \item снижение частоты не ниже 45 Гц (отсутствие выходного сигнала «АЧР(n) (m): ИО F<45»);
    \item наличие напряжения на основной секции контролируемое уставкой SGF2 (отсутствие выходного сигнала «АЧР(n) (m): ИО U<»);
    \item отсутствие сигналов блокировки «БНН: Срабатывание», «БССЧ: Срабатывание», «Блокировка АЧР(n) (m)»;
    \item наличие разрешающего сигнала от смежной секции «КССШ: Срабатывание».
\end{itemize}

\item
Ввод контролей блокировки по скорости снижения частоты и контроль частоты смежной секции осуществляется с помощью соответствующих уставок SGF3 «Контр\_БССЧ», SGF4 «Контр\_КССШ».

\item
Срабатывание ступени происходит после отсчета выдержки времени, задаваемая уставкой Т1.

\item
При активном состоянии входного сигнала «АЧР(n) (m)» (ключ «АЧР(n) (m)» введен) действие ступени АЧР переводится на сигнал.

\item
Предусмотрена возможность продления сигнала пуска ИО частоты на время, задаваемое уставкой Т2.

\item
Ввод ступени «АЧР(n) (m)» в работу на этапе параметрирования устройства осуществляется своим программным переключателем SGF1 «Ввод\_функции». Информация о введенной функции отображается выходным сигналом «АЧР(n) (m): Ввод».
\item
Ступень «АЧР(n) (m)» может быть выведена из работы оперативно путем активации сигнала «ОВ АЧР» (совместно со всеми функциями устройства АЧР). Состояние ступени характеризуется активным состоянием сигнала «АЧР(n) (m): Оперативный вывод».

\item
При активном состоянии входного сигнала «АЧР(n) (m) на сигн» действие соответствующей ступени АЧР переводится на сигнал.

\item Специальная очередь АЧР (САЧР) \label{punktsachr}

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
Специальная очередь АЧР предназначена для предотвращения автоматической или оперативной разгрузки энергоблоков АЭС при снижении частоты ниже 49,0 Гц и срабатывания основного объема АЧР. В устройстве специальная очередь АЧР представлена функцией «САЧР».

\item
Для срабатывания функции необходимо одновременное наличие следующих условий:
\begin{itemize}
    \item функция введена в работу;
    \item снижение частоты ниже уставки (наличие выходного сигнала «САЧР: ИО F<»);
    \item снижение частоты не ниже 45 Гц (отсутствие выходного сигнала «САЧР: ИО F<45»);
    \item наличие напряжения на основной секции контролируемое уставкой SGF2 (отсутствие выходного сигнала «САЧР: ИО U<»);
    \item отсутствие сигналов блокировки «БНН: Срабатывание», «БССЧ: Срабатывание», «Блокировка САЧР»;
    \item наличие разрешающего сигнала от смежной секции «КССШ: Срабатывание».
\end{itemize}

\item
Ввод контролей блокировки по скорости снижения частоты и контроль частоты смежной секции осуществляется с помощью соответствующих уставок SGF3 «Контр\_БССЧ», SGF4 «Контр\_КССШ».

\item
Срабатывание функции происходит после отсчета выдержки времени, задаваемая уставкой Т1.

\item
При активном состоянии входного сигнала «САЧР на сигн» (ключ «АЧР(n) (m)» введен) действие функции переводится на сигнал.

\item
Предусмотрена возможность продления сигнала пуска ИО частоты на время, задаваемое уставкой Т2.

\item
Ввод САЧР в работу на этапе параметрирования устройства осуществляется своим программным переключателем SGF1 «Ввод\_функции». Информация о введенной функции отображается выходным сигналом «САЧР: Ввод».

\item
Функция может быть выведена из работы оперативно путем активации сигнала «ОВ АЧР» (совместно со всеми функциями устройства АЧР). Состояние ступени характеризуется активным состоянием сигнала «САЧР: Оперативный вывод».

\item
При активном состоянии входного сигнала «САЧР на сигн»  действие функции переводится на сигнал.

\item Частотное автоматическое повторное включение (ЧАПВ) \label{punktchapv}

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
ЧАПВ предназначено для автоматического включения отключенных устройствами АЧР потребителей электрической энергии в процессе восстановления частоты в энергосистеме. В составе устройства ЧАПВ представлено функциями (очередями) частотного автоматического включения.

\item
Условием пуска очередей служит одновременное выполнение следующих условий:
\begin{itemize}
    \item функция введена в работу (наличие выходного сигнала «ЧАПВ(m): Ввод»);
    \item повышение частоты выше уставки (наличие выходного сигнала «ЧАПВ(m): ИО F>»);
    \item наличие напряжения на основной секции, контролируемое уставкой SGF2 (отсутствие выходного сигнала «ЧАПВ(m): ИО U<»);
    \item отсутствие сигналов блокировки «БНН: Срабатывание», «Блокировка ЧАПВ(m)»;
    \item наличие выходного сигнала «ЧАПВ(m): Разрешение».
\end{itemize}

\item
Срабатывание очереди ЧАПВ возможно только после срабатывания очереди АЧР. После окончания срабатывания очереди АЧР и отсутствии выходного сигнала «ЧАПВ(m): Блок.повт.ЧАПВ(m)», таймером Т4 продлевается входной сигнал «АЧРобщ: Срабатывание» на время 5 мс, формируя выходной сигнал «ЧАПВ(m): Разрешение». Если частота восстановилась до порога срабатывания одной из очередей ЧАПВ, происходит пуск очереди. В случае сохранения пусковых условий запускается выдержка времени Т1 и происходит срабатывание ЧАПВ данной очереди.

\item
Для обеспечения однократности действия очереди ЧАПВ при повторном срабатывании АЧР предусмотрена уставка SGF3 «Блок\_повт\_ЧАПВ». Если данная уставка введена, после срабатывания очереди ЧАПВ формируется сигнал «ЧАПВ(m): Блок.повт.ЧАПВ(m)», а повторное срабатывание данной очереди блокируется. Блокировка может быть сброшена либо оперативно с помощью ФК «Возврат ЧАПВ/АПВН», либо автоматически через выдержку времени T2 при введенной уставке SGF4 «Авт\_возвр\_ЧАПВ».

\item
Сброс сигнала разрешения осуществляется несколькими способами:
\begin{itemize}
    \item выводом функции из работ;
    \item принудительно от кнопки «Возврат ЧАПВ/АПВН»;
    \item после прохождения сигнала пуска ЧАПВ(m) через выдержку времени Т1;
    \item через выдержку времени Т3, при наличии длительного срабатывания сигнала АЧР при введенной уставке SGF5 «Сброс\_ЧАПВ».
\end{itemize}

\item
Ввод очередей в составе функции ЧАПВ в работу на этапе параметрирования устройства осуществляется своим программным переключателем SGF1 «Ввод\_функции». Информация о введенной очереди отображается выходным сигналом «ЧАПВ(m): Ввод».

\item
Очередь ЧАПВ может быть выведена из работы оперативно путем активации сигнала «ОВ ЧАПВ» (совместно со всеми ступенями устройства ЧАПВ). Состояние ступени характеризуется активным состоянием сигнала «ЧАПВ(m): Оперативный вывод».

\item
При активном состоянии входного сигнала «ЧАПВ(m) на сигн»  действие ступени ЧАПВ переводится на сигнал.
