\color{uniblue}{\subsection{Защита от повышения напряжения (ЗПН)}}
\color{black}

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic*, labelsep=4pt, leftmargin=0pt, itemindent=57pt]

\item
Функция <<ЗПН>> отслеживает повышение напряжения на секции шин и формирует команду на отключение выключателя. В устройстве предусмотрены две независимые функции ЗПН (ЗПН 1, ЗПН 2).
\item
Пусковые условия формируются от ИО напряжения, реагирующих на превышение хотя бы одного из трех линейных напряжений выше уставки, отсутствии условий блокировки и выбора определенного режима работы уставки SGF2.

\item
При превышении ИО напряжения выше уставки активируются соответствующие выходные сигналы срабатывания ИО:
\begin{itemize}
    \item <<ЗПН 1: ИО Uab>>;
    \item <<ЗПН 1: ИО Ubc>>;
    \item <<ЗПН 1: ИО Uca>>.
\end{itemize}

\item
Посредством уставки SGF2 предоставляется возможность настройки работы функции в одном из трех режимов:
\begin{itemize}
    \item по превышению одного линейного напряжения;
    \item по превышению двух линейных напряжений;
    \item по превышению трех линейных напряжений.
\end{itemize}
\item
Обязательным условием формирования выходных сигналов пуска и срабатывания функции является отсутствие активного сигнала блокировки от неисправности цепей напряжения ТН <<БНН: Срабатывание>>.
\item
При превышении ИО напряжения ОП выше уставки активируется соответствующий выходной сигнал срабатывания ИО <<ЗПН 1: ИО U2>>m <<ЗПН 2: ИО U2>>.
\item
Уставкой SGF3 в функции предусмотрен контроль симметрии по напряжению обратной последовательности. В режиме работы по трем линейным напряжениям и увеличению напряжения ОП, пуск и срабатывание функции будет заблокировано.

\item
При наличии пусковых условий, срабатывание ступени происходит после отсчета выдержки времени, таймера T1.

\item
Ввод функции <<ЗПН>> в работу на этапе параметрирования устройства осуществляется программным переключателем SGF1 <<Ввод\_функции>> для каждой функции <<ЗПН>>. Информация о введенной ступени отображается выходным сигналом <<ЗПН1: Ввод>>, <<ЗПН2: Ввод>>.
\item
Функция <<ЗПН>> может быть выведена из работы оперативно путем активации сигнала <<ОВ ЗПН 1>> <<ОВ ЗПН 2>>, что характеризуется активным состоянием сигнала <<ЗПН 1: Оперативный вывод>>, <<ЗПН 2: Оперативный вывод>>.

\item
При активном состоянии входного сигнала <<ЗПН 1 на сигн>>, <<ЗПН 2 на сигн>> действие соответствующей функции <<ЗПН>> переводится на сигнал.

\item
Алгоритм работы ступени <<ЗПН>> выполнен в соответствии с рисунком \ref{zpn:img1}. В таблице \ref{zpn:tbl1} приведены параметры, необходимые для настройки функции <<ЗПН>>.
