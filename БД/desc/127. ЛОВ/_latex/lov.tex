\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}, labelsep=4pt, leftmargin=0pt, itemindent=57pt, itemsep=0pt, parsep=5pt] % если что можно крутить itemsep

\item Общие сведения

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
Логика отключения/включения выключателя предназначена для подачи аварийных команд управления на выключатель при действии устройств РЗА. В устройстве логика представлена функциональным блоком «ЛОВ».

\item
Функциональный блок состоит из следующих функций:
\begin{itemize}
\item логика отключения от релейной защиты (ЛО РЗ); 
\item логика отключения от противоаварийной автоматики (ЛО ПА);
\item логика включения от противоаварийной автоматики (ЛВ ПА);
\item логика запрета АПВ (ЗАПВ).
\end{itemize}

\item
Функциональный блок может быть полностью выведен из работы оперативно путем активации сигнала «ОВ ЛОВ».

\end{enumerate}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%% Логика отключения от релейной защиты (ЛО РЗ) %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\item Логика отключения от релейной защиты (ЛО РЗ)

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
ЛО РЗ формирует сигналы аварийного отключения («ЛО РЗ: Отключение», «ЛО РЗ: Отключить») при срабатывании функций релейной защиты в составе устройства, а также от четырех назначаемых сигналов внешнего отключения («Откл. внешнее 1-4»). В функциональном блоке «ЛОВ» логика отключения представлена функцией «ЛО РЗ». 

\item
Сигнал «ЛО РЗ: Отключение» является суммарным сигналом отключения от отдельных функций и существует пока активен хотя бы один сигнал срабатывания защитных функций.

\item
Сигнал «ЛО РЗ: Отключить» воздействует на выходные реле для отключения выключателя, длительность сигнала задается уставкой Т1.

\item
Ввод функции в работу на этапе параметрирования устройства осуществляется программным переключателем SGF1 «Ввод\_функции». Информация о введенной функции отображается выходным сигналом «ЛО РЗ: Ввод».

\item
Функция может быть выведена из работы оперативно путем активации сигнала «ОВ ЛО РЗ», что характеризуется активным состоянием сигнала «ЛО РЗ: Оперативный вывод» на выходе функции.

\item
Алгоритм работы функции выполнен в соответствии с рисунком \ref{lorz:img1}. В таблице \ref{lorz:tbl1} приведены параметры, необходимые для настройки функции.

\item Логика отключения от противоаварийной автоматики (ЛО ПА)

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
ЛО ПА формирует сигналы аварийного отключения («ЛО ПА: Отключение», «ЛО ПА: Отключить») при срабатывании внешних функций противоаварийной автоматики, с учетом внешнего сигнала блокировки «Блок. команд ПА». В функциональном блоке «ЛОВ» логика отключения представлена функцией «ЛО ПА». 

\item
Сигнал «ЛО ПА: Отключение» является сигналом отключения от внешних функций ПА и существует пока активен сигнал «Отключение от ПА» на входе устройства с учетом внешнего сигнала блокировки «Блок. команд ПА».

\item
Сигнал «ЛО ПА: Отключить» воздействует на выходные реле для отключения выключателя, длительность сигнала задается уставкой Т1.

\item
Ввод функции в работу на этапе параметрирования устройства осуществляется программным переключателем SGF1 «Ввод\_функции». Информация о введенной функции отображается выходным сигналом «ЛО ПА: Ввод».

\item
Функция может быть выведена из работы оперативно путем активации сигнала «ОВ ПА», что характеризуется активным состоянием сигнала «ЛО ПА: Оперативный вывод» на выходе функции.

\item Логика включения от противоаварийной автоматики (ЛВ ПА)

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
ЛВ ПА формирует сигнал аварийного включения «ЛВ ПА: Включить» при срабатывании внешних функций противоаварийной автоматики на включение присоединения. В функциональном блоке «ЛОВ» логика отключения представлена функцией «ЛО ПА».

\item
Функция предусматривает пуск как от внутреннего, так и от внешнего сигнала. Тип пуска выбирается уставкой SGF2:
\begin{itemize}
    \item Тип пуска «Внутренний». В данном типе пуска активный сигнал на отключение от ПА в случае аварийного отключения выключателя является необходимым условием для срабатывания триггера. Таймер Т3 уменьшает время прохождения сигнала до 1 секунды. При пропадании сигнала отключения от ПА, отсутствии блокировки команд ПА и отсутствии условий сброса RS-триггера формируются пусковые условия функции.
    \item Тип пуска «Внешний». В данном режиме пуск функции будет осуществлен при наличии вышеописанных условий и внешнего дискретного сигнала на входе устройства. 
\end{itemize}    
\item    
Сброс триггера осуществляется при наличии одного из условий:
\begin{itemize}
    \item функция выведена из работы;
    \item выключатель аварийно отключился в результате срабатывания логики отключения от релейной защиты (РЗ). Если сигнал «ЛО РЗ: Отключение» пропал, то этот сигнал продлится на время таймера Т4, которое составляет 1 секунду;
    \item отсутствие сигнала РФК из логики КСВ.
\end{itemize}

\item
По истечении выдержки времени таймера Т1 и отсутствии блокировки включения из логики КСВ формируется команда на включение выключателя. При сохранении условий пуска, по истечении выдержки времени таймера Т1 происходит сброс триггера восстанавливая схему в исходное состояние.

\item
Ввод функции в работу на этапе параметрирования устройства осуществляется программным переключателем SGF1 «Ввод\_функции». Информация о введенной функции отображается выходным сигналом «ЛВ ПА: Ввод».

\item
Функция может быть выведена из работы оперативно путем активации сигнала «ОВ ПА», что характеризуется активным состоянием сигнала «ЛВ ПА: Оперативный вывод» на выходе функции.

\item Логика запрета АПВ (ЗАПВ)

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
Запрет АПВ может быть необходим в определённых ситуациях для предотвращения повторных срабатываний и возможных повреждений оборудования. В функциональном блоке «ЛОВ» логика запрета АПВ представлена функцией «ЗАПВ».

\item
Сигнал «ЗАПВ: Запрет АПВ» формируется, если присутствует сигнал срабатывания защит на любом из входов, которые заведены под запрет АПВ с помощью выбора уставки программного переключателя. Контроль всех входных сигналов, выполняется соответствующими уставками (SGF1 \ldots SGF42).

\item
Ввод функции в работу осуществляется при введенной функции АПВ в работу. Информация о введенной функции отображается выходным сигналом «ЗАПВ: Ввод».

\item
Функция может быть выведена из работы оперативно путем активации сигнала «ОВ ЛОВ», что характеризуется активным состоянием сигнала «ЗАПВ: Оперативный вывод» на выходе функции.
