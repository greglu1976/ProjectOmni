\color{uniblue}{\subsection{Контроль цепей напряжения стороны НН трансформатора (КЦН НН)}}
\color{black}

\begin{enumerate}

\item
Контроль цепей напряжения стороны НН трансформатора служит для контроля исправности цепей напряжения стороны НН трансформатора.

% ЗДЕСЬ ВЕТВЛЕНИЕ, если исполнение Т2 то вставляем первый абзац
\ifboolexpr{bool {isT2}}
{
    \item
    В устройстве модули контроля цепей напряжения сторон НН1 и НН2 представлены функциональными блоками «КЦН НН1» и «КЦН НН2» соответственно, каждый из этих блоков который состоит из одной функции «КЦН». Далее представлено описание функции «КЦН».
}
{
    \item
    В устройстве контроль цепей напряжения представлен функциональным блоком «КЦН НН», который состоит из одной функции «КЦН».
}

\item
Ввод функции в работу на этапе параметрирования устройства осуществляется программным переключателем SGF1 «Ввод\_функции». Информация о введенной функции отображается выходным сигналом «КЦН НН: Ввод».

\item
Функция может быть выведена из работы оперативно путем активации сигнала «ОВ КЦН НН», что характеризуется активным состоянием сигнала «КЦН НН: Оперативный вывод» на выходе функции.

\item
Функция контролирует снижение максимального из линейных напряжений ($U_{AB}, U_{BC}, U_{CA}$) ниже заданной уставки и повышение напряжения обратной последовательности ($U_2$) выше заданной уставки, в случае выполнения любого из условий через выдержку времени таймера Т1 (уставка «Тср») выдается сигнал неисправности ЦН.

\item
Алгоритм работы КЦН НН1 выполнен в соответствии с рисунком \ref{kznnn:img1}. Алгоритм работы КЦН НН2 выполняется аналогично КЦН НН1.
\ifboolexpr{bool {isT}} {В таблице \ref{kznnn:tbl1} приведены параметры, необходимые для настройки КЦН НН.}{}
\ifboolexpr{bool {isT2}} {В таблице \ref{kznnn:tbl1} приведены параметры, необходимые для настройки КЦН НН1. В таблице \ref{kznnn1:tbl1} приведены параметры, необходимые для настройки КЦН НН2.}{}
