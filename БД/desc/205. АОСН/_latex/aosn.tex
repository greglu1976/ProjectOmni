\color{black}

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}, labelsep=4pt, leftmargin=0pt, itemindent=57pt, itemsep=0pt, parsep=5pt] % если что можно крутить itemsep

\item Общие сведения

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
Автоматическое ограничение снижения напряжения необходимо для предотвращения развития аварий, сопровождающихся глубоким снижением напряжения. Функция применяется для предотвращения снижения напряжения в узлах энергосистемы, вызванного дефицитом реактивной мощности до значения, опасного по условиям устойчивости энергосистемы и возникновения лавины напряжения, путем отключения части нагрузки с последующим включением отключенной нагрузки при восстановлении напряжения.

\item
АОСН включает в себя следующие функции:
\begin{itemize}
    \item три очереди АОСН, см. п.\ref{punktaosn};
    \item 15 функций для реализации управляющих воздействий очередей УВ АОСН, см. п.\ref{punktstaosn};
    \item три функции АПВН, см. п.\ref{punktapvn};
    \item 15 функций для реализации управляющих воздействий функций УВ АПВН;
    \item общая функция объединения срабатывания функций в составе функционального блока <<АОСН>>.   
\end{itemize}

\item
Основные характеристики АОСН:
\begin{itemize}
    \item основная погрешность срабатывания ИО частоты не более 20 мГц;
    \item основная погрешность возврата ИО частоты не более 20 мГц;
    \item основная погрешность ИО частоты в рабочем диапазоне при напряжении входного сигнала 100 В не более 10 мГц;
    \item время срабатывания и возврата ИО частоты не более 60 мс;
    \item основная относительная приведенная погрешность измерения по напряжению в рабочем диапазоне при частоте входного сигнала (50 ± 0,5) Гц составляет ± 3,0\%;
    \item дополнительная погрешность измерения напряжения и тока при изменении частоты входного сигнала в рабочем диапазоне на каждый 1 Гц составляет ± 0,5\%.
\end{itemize}

\item
Функциональный блок <<АОСН>> может быть полностью выведен из работы оперативно путем активации сигнала <<ОВ АОСН/АПВН>>.

\end{enumerate}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%  ОЧЕРЕДЬ АОСН %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\item Очереди АОСН (АОСН1, АОСН2, АОСН3)\label{punktaosn}

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
Ввод каждой очереди АОСН в работу на этапе параметрирования устройства осуществляется своим программным переключателем SGF1 <<Ввод\_функции>>. Информация о введенной очереди отображается выходным сигналом для каждой очереди <<АОСН(n): Ввод>>, здесь и далее в этом подразделе: (n) -- номер очереди, $n\in\{1,2,3\}$.

\item
Очереди <<АОСН>> могут быть выведены из работы оперативно путем активации общего сигнала вывода всех трех очередей <<ОВ АОСН>> либо по отдельности каждая своим сигналом оперативного вывода(<<ОВ АОСН(n)>>). Состояние очереди характеризуется активным состоянием сигнала <<АОСН(n): Оперативный вывод>> на выходе функции.

\item
При активном состоянии входного сигнала <<АОСН(n) на сигн>>  действие очереди (n) АОСН переводится на сигнал.

\item
В каждой из очередей предусмотрены следующие измерительные органы:
\begin{itemize}
    \item ИО минимального действия по значению линейным напряжениям. Срабатывание осуществляется при снижении минимального из поданных напряжений ниже уставки;
    \item два ИО минимального действия по напряжению ПП на двух секциях. Срабатывание происходит при снижении напряжений прямой последовательности на каждой из двух секциях ниже уставок;
    \item ИО максимального действия по напряжению обратной последовательности. Срабатывание происходит при превышении значения напряжения уставки напряжения ОП;
    \item ИО по снижению частоты. Функция реагирует на снижение значения частоты ниже уставки;
    \item ИО по скорости снижения напряжения $dU/dt$. Срабатывание происходит при превышении скорости снижения напряжения уставки.
\end{itemize}

\item
Пусковым условием АОСН является одновременное выполнение условий:
\begin{itemize}
    \item отсутствие сигналов: срабатывания напряжения обратной последовательности, скорости снижения напряжения, линейных напряжений (реализованных через выдержку времени на срабатывание T3 и подхвата T4), снижение частоты ниже порогового значения;
    \item снижение напряжения на обеих секциях;
    \item отсутствие срабатываний БНН и блокировки АОСН.
\end{itemize}

\item
В случае снижения напряжения прямой последовательности основной и смежной секции до порога срабатывания очереди АОСН, запускается выдержка времени данной очереди и в случае сохранения пусковых условий, происходит срабатывание данной очереди АОСН. Кроме того, необходимо отсутствие остальных блокирующих сигналов АОСН, как общих, так и по каждой очереди.

\item
Блокировка пуска очереди АОСН осуществляется при выполнении одного из условий:
\begin{itemize}
    \item срабатывание ИО ОП при введенной уставке SGF2;
    \item срабатывание ИО по скорости снижения напряжения при введенной уставке SGF3;
    \item срабатывание ИО по скорости снижения напряжения по истечению времени таймера Т3. При пропадании сигнала, блокировка снимается по истечению времени таймера Т4;
    \item наличие входных сигналов <<БНН: Срабатывание>>, <<Блокировка АОСН(n)>>.
\end{itemize}

\item
Срабатывание очереди АОСН происходит при наличии пускового сигнала через выдержку времени T1 и при отсутствии сигнала <<АОСН(n) на сигн>>. При наличии сигнала <<АОСН(n) на сигн>> действие очереди переводится на сигнал <<АОСН(n): Срабатывание сигн>>, при этом выходной сигнал <<АОСН(n): Срабатывание>> блокируется.
\item
Для исключения кратковременных пусков ступеней, в соответствии с ГОСТ Р 70411-2022, предусмотрена возможность продления сигнала пуска ИО частоты на время, задаваемое уставкой Т2.

\item Функции АПВН (АПВН1, АПВН2, АПВН3) \label{punktapvn}

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
После срабатывания АОСН возникает необходимость автоматической сборки нормальной схемы при восстановлении рабочего уровня напряжения, для этого в устройстве предусмотрена функция автоматического повторного включения по напряжению.

\item
Ввод каждой функции <<АПВН>> в работу на этапе параметрирования устройства осуществляется своим программным переключателем SGF1 <<Ввод\_функции>>. Информация о введенной функции отображается выходным сигналом для каждой функции <<АПВН(n): Ввод>>.

\item
Функции <<АПВН>> могут быть выведены из работы оперативно путем активации общего сигнала вывода всех трех функций <<ОВ АПВН>> либо по отдельности каждая своим сигналом оперативного вывода(<<ОВ АПВН(n)>>). Состояние очереди характеризуется активным состоянием сигнала <<АПВН(n): Оперативный вывод>> на выходе функции.

\item
При активном состоянии входного сигнала <<АПВН(n) на сигн>>  действие функции (n) АПВН переводится на сигнал.

\item
В каждой из функций предусмотрены следующие измерительные органы:
\begin{itemize}
    \item ИО максимального действия по значению напряжения прямой последовательности. Срабатывание осуществляется при превышении напряжения заданной уставки;
    \item ИО по снижению частоты. Функция реагирует на снижение частоты ниже уставки.
\end{itemize}





\item
Пусковым условием АОСН является одновременное выполнение условий:
\begin{itemize}
    \item отсутствие сигналов: срабатывания напряжения обратной последовательности, скорости снижения напряжения, линейных напряжений (реализованных через выдержку времени на срабатывание T3 и подхвата T4), снижение частоты ниже порогового значения;
    \item снижение напряжения на обеих секциях;
    \item отсутствие срабатываний БНН и блокировки АОСН.
\end{itemize}

\item
В случае снижения напряжения прямой последовательности основной и смежной секции до порога срабатывания очереди АОСН, запускается выдержка времени данной очереди и в случае сохранения пусковых условий, происходит срабатывание данной очереди АОСН. Кроме того, необходимо отсутствие остальных блокирующих сигналов АОСН, как общих, так и по каждой очереди.

\item
Блокировка пуска очереди АОСН осуществляется при выполнении одного из условий:
\begin{itemize}
    \item срабатывание ИО ОП при введенной уставке SGF2;
    \item срабатывание ИО по скорости снижения напряжения при введенной уставке SGF3;
    \item срабатывание ИО по скорости снижения напряжения по истечению времени таймера Т3. При пропадании сигнала, блокировка снимается по истечению времени таймера Т4;
    \item наличие входных сигналов <<БНН: Срабатывание>>, <<Блокировка АОСН(n)>>.
\end{itemize}

\item
Срабатывание очереди АОСН происходит при наличии пускового сигнала через выдержку времени T1 и при отсутствии сигнала <<АОСН(n) на сигн>>. При наличии сигнала <<АОСН(n) на сигн>> действие очереди переводится на сигнал <<АОСН(n): Срабатывание сигн>>, при этом выходной сигнал <<АОСН(n): Срабатывание>> блокируется.
