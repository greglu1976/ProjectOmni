\color{uniblue}{\subsection{Логика отключения (ЛО)}}
\color{black}

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}, labelsep=4pt, leftmargin=0pt, itemindent=57pt, itemsep=0pt, parsep=5pt] % если что можно крутить itemsep
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%  ОБЩИЕ СВЕДЕНИЯ %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\item Общие сведения

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
Функция логики отключения выключателя предназначена для подачи аварийных команд отключения на выключатель при действии устройств РЗА.

\item
Функциональный блок <<ЛО>> состоит из следующих функций:
\begin{itemize}
\item логика отключения от релейной защиты (ЛО РЗ); 
\item логика отключения ВНР (ЛО ВНР);
\item Логика запрета АВР (ЗАВР ЛО).
\end{itemize}

\item
Функциональный блок <<ЛО>> может быть полностью выведен из работы оперативно путем активации сигнала <<ОВ ЛО>>.

\end{enumerate}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%% Логика отключения от релейной защиты (ЛО РЗ) %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\item Логика отключения от релейной защиты (ЛО РЗ)

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
Функция <<ЛО РЗ>> формирует сигналы аварийного отключения (<<ЛО РЗ: Отключение>>, <<ЛО РЗ: Отключить>>) при срабатывании функций релейной защиты в составе устройства, а также от четырех назначаемых сигналов внешнего отключения (<<Откл. внешнее 1-4>>).

\item
Сигнал <<ЛО РЗ: Отключение>> является суммарным сигналом отключения от отдельных функций и существует пока активен хотя бы один сигнал срабатывания защитных функций.

\item
Сигнал <<ЛО РЗ: Отключить>> воздействует на выходные реле для отключения выключателя, длительность сигнала задается уставкой Т1.

\item
Ввод функции в работу на этапе параметрирования устройства осуществляется программным переключателем SGF1 <<Ввод\_функции>>. Информация о введенной функции отображается выходным сигналом <<ЛО РЗ: Ввод>>.

\item
Функция <<ЛО РЗ>> может быть выведена из работы оперативно путем активации сигнала <<ОВ ЛО РЗ>>, что характеризуется активным состоянием сигнала <<ЛО РЗ: Оперативный вывод>> на выходе функции.

\item
Алгоритм работы функции <<ЛО РЗ>> выполнен в соответствии с рисунком \ref{lorz:img1}. В таблице \ref{lorz:tbl1} приведены параметры, необходимые для настройки пускового органа <<ЛО РЗ>>.

\item Логика запрета АВР (ЗАВР ЛО)

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
Запрет АВР может быть необходим в определённых ситуациях для предотвращения повторных срабатываний и возможных повреждений оборудования.
\item
Сигнал <<ЗАВР: Запрет АВР>> формируется, если присутствует сигнал срабатывания защит на любом из входов, которые заведены под запрет АВР с помощью выбора уставки программного переключателя. Контроль всех входных сигналов внешнего отключения выполняется соответствующими уставками (SGF1 \ldots SGF4).

\item
Ввод функции в работу осуществляется при введенной функции АВР в работу (<<АВР: Ввод>>). Информация о введенной функции отображается выходным сигналом <<ЛОВ / ЗАВР: Ввод>>.

\item
Функция <<ЗАВР ЛО>> может быть выведена из работы оперативно путем активации сигнала <<ОВ ЛОВ>>, что характеризуется активным состоянием сигнала <<ЛОВ / ЗАВР: Оперативный вывод>> на выходе функции.

Алгоритм работы функции <<ЗАВР ЛО>> выполнен в соответствии с рисунком \ref{zavr:img1}. В таблице \ref{zavr:tbl1} приведены параметры, необходимые для настройки пускового органа <<ЗАВР ЛО>>.
