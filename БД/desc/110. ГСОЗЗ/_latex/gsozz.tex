\color{uniblue}{\subsection{Групповая сигнализация однофазных замыканий на землю (ГСОЗЗ)}}
\color{black}

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic*, labelsep=4pt, leftmargin=0pt, itemindent=57pt]

\item
Групповая сигнализация однофазных замыканий на землю предназначена для селективного выявления однофазных замыканий на землю в сетях с изолированной нейтралью, в сетях с заземлением нейтрали через дугогасящий реактор или высокоомный резистор. 

\item В устройстве групповая сигнализация однофазных замыканий на землю представлена функцией «ГСОЗЗ». Основные характеристики функции:
\begin{itemize}
    \item погрешность срабатывания ИО тока по высшим гармоникам не более 20\%.
\end{itemize}

\item
Функция имеет в своем составе три измерительных органа:
\begin{itemize}
    \item ИО 3I0;
    \item ИО 3I0 по высшим гармоникам;
    \item ИО 3U0.
\end{itemize}

\item 
В зависимости от выбранных уставок программных переключателей SGF2, SGF4 возможны следующие варианты работы функции:
\begin{itemize}
    \item по току НП (3I0);
    \item по действующему значению суммы 3-й, 5-й, 7-й, 9-й и 11-й гармоник тока НП (3I0вг);
    \item по току НП (3I0) с контролем напряжения НП (3I0+3U0);
    \item по действующему значению суммы 3-й, 5-й, 7-й, 9-й и 11-й гармоник тока НП с контролем напряжения НП (3I0вг+3U0);
\end{itemize}

\item 
Пуски измерительных органов происходят при превышении воздействующей величины срабатывания выше уставки и приводят к появлению соответствующих сигналов на выходе таких как: «ГСОЗЗ: ИО 3I0», «ГСОЗЗ: ИО 3I0вг» и «ГСОЗЗ: ИО 3U0». Возврат ИО происходит при снижении воздействующей величины ниже величины уставки.

\item 
Функция реализуется на группе отходящих присоединений и включает в себя устройства, содержащие функцию ГСОЗЗ с зависимыми время-токовыми характеристиками, параметры и уставки которых идентичны. Сигнализация селективно выявляет поврежденное присоединение по наибольшему значению тока НП, в результате первой срабатывает сигнализация устройства, на присоединении которого произошло ОЗЗ и сигнал срабатывания функции передается устройствам смежных присоединений на дискретный вход «Сраб.ГСОЗЗ смеж.», что приводит к блокировке пуска функции.

\item 
Пусковые условия функции могут формироваться с контролем напряжения нулевой последовательности так и без него. Контроль напряжения нулевой последовательности вводится уставкой SGF2. Если предусматривается работа функции без учета $3U_0$ (уставка SGF2 выведена из работы) то пусковые условия функции формируются от ИО 3I0 или ИО 3I0вг (уставка SGF4).

\item 
Порядок работы функции при неисправности цепей напряжения в режиме работы ПО 3U0 определяется уставкой SGF3 которая имеет два положения – «блокировка» или «деблокировка». В режиме «блокировка», работа функции запрещается до момента исчезновения неисправности в ЦН (отсутствие сигнала «БННш: Срабатывание»). В режиме «деблокировка» разрешается работа функции при наличии неисправности в ЦН (активный сигнал «БННш: Срабатывание») без учета пуска ИО 3U0.

\item
Выбор характеристик срабатывания для формирования сигнала «ГСОЗЗ: Срабатывание сигн» осуществляется программным переключателем «Характеристика». Графики реализованных в устройстве обратнозависимых времятоковых характеристик приведены в приложении \ref{app:chars}.

\item
%\sloppy % потому что здесь криво выводит строку
Ввод функции в работу на этапе параметрирования устройства осуществляется программным переключателем SGF1 «Ввод\_функции». Информация о введенной функции отображается выходным сигналом «ГСОЗЗ: Ввод».
\item
Функция может быть выведена из работы оперативно путем активации сигнала «ОВ~ГСОЗЗ», что характеризуется активным состоянием сигнала «ГСОЗЗ: Оперативный вывод» на выходе функции.
 \item
При активном состоянии входного сигнала «ГСОЗЗ на откл» действие защиты переводится на отключение. В этом случае одновременно с активацией выходного сигнала «ГСОЗЗ: Срабатывание сигн» выдается сигнал на отключение «ГСОЗЗ: Срабатывание».

\item
Алгоритм работы функции выполнен в соответствии с рисунком \ref{gsozz:img1}. В таблице \ref{gsozz:tbl1} приведены параметры, необходимые для настройки функции.

\end{enumerate}
