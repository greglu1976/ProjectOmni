\color{uniblue}{\subsection{Контроль наличия напряжения на шинах (КННш)}}
\color{black}

\begin{enumerate}

\item
В устройстве контроль наличия напряжения на шинах представлен функцией «КННш». Функция контролирует наличие напряжения на секции шин с дополнительным контролем симметрии по $U_2$.
% УСЛОВНОЕ ВЫРАЖЕНИЕ
\ifboolexpr{bool {isVV}}
{
    Функция используется для АПВ и АВР, а также для оперативного включения.
}
{
    Функция используется для АПВ, а также для оперативного включения.
}

\item
Пусковые условия функции формируются без выдержки времени при превышении всех линейных напряжений на шинах выше уставки и одновременном выполнении следующих условий, если уставка SGF2 выставлена в положение «Измеренный»:
\begin{itemize}
    \item функция введена в работу;
    \item минимальное из подведенных линейных напряжений, измеренных с ТН шин, выше уставки;
    \item отсутствует срабатывание ИО напряжения обратной последовательности.
\end{itemize}
\item
Предусмотрена блокировка функции при срабатывании ИО обратной последовательности напряжения выше уставки.

\item
Если уставка SGF2 выставлена в положение «Внешний», работа функции осуществляется при наличии активного внешнего дискретного сигнала «Наличие Uш» без учета срабатывания измерительных органов.

\item
Ввод функции в работу на этапе параметрирования устройства осуществляется программным переключателем SGF1 «Ввод\_функции». Информация о введенной функции отображается выходным сигналом «КННш: Ввод».

\item
Функция может быть выведена из работы оперативно путем активации сигнала «ОВ КННш», что характеризуется активным состоянием сигнала «КННш: Оперативный вывод» на выходе функции.

\item
Алгоритм работы функции выполнен в соответствии с рисунком \ref{knnsh:img1}. В таблице \ref{knnsh:tbl1} приведены параметры, необходимые для настройки функции.
