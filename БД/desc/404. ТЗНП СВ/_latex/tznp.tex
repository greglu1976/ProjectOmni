\item Общие сведения

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
Токовая защита нулевой последовательности предназначена для селективной защиты от замыканий на землю в линиях среднего и высокого напряжения, а также для резервирования защит трансформаторов при замыканиях на землю в сети низкого напряжения, работающей с заземленной нейтралью.

\item
Устройство содержит четыре ступени ТЗНП с независимой выдержкой времени от КЗ на землю, реагирующие на первую гармонику тока нулевой последовательности.

\item
Основные характеристики функционального блока <<ТЗНП>>:
\begin{itemize}
    \item погрешность по углу при номинальных значениях тока и напряжения не более 5$^\circ$.
\end{itemize}

\item
Логическая часть реализует группу пусковых органов с независимыми уставками, предусматривает таймеры выдержек времени на срабатывание, логику пусков и блокировок, коммутацию внутренних пусковых сигналов для формирования выходного сигнала автоматического ускорения.

\item
ТЗНП может применяться в качестве:
\begin{itemize}
    \item селективной защиты от замыканий на землю в линиях среднего и высокого напряжения;
    \item резервной защиты трансформаторов при замыканиях на землю в сети низкого напряжения, работающей с заземленной нейтралью;
\end{itemize}

\item
В составе функционального блока <<ТЗНП>> предусмотрены следующие функции:
\begin{itemize}
\item четыре независимые направленные/ненаправленные ступени;
\item блокировка при броске намагничивающего тока;
\item орган направления мощности нулевой последовательности.
\end{itemize}

\item
Функциональный блок <<ТЗНП>> может быть полностью выведен из работы оперативно путем активации сигнала <<ОВ ТЗНП>>.

\end{enumerate}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%  СТУПЕНЬ ТЗНП %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\item Ступени токовой защиты нулевой последовательности (ТЗНП 1 ст., ТЗНП 2 ст.)

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
Ввод каждой ступени ТЗНП в работу на этапе параметрирования устройства осуществляется своим программным переключателем SGF1 <<Ввод\_функции>>. Информация о введенной ступени отображается выходным сигналом для каждой ступени (<<ТЗНП 1 ст: Ввод>>, <<ТЗНп 2 ст: Ввод>>, <<ТЗНП 3 ст: Ввод>>, <<ТЗНп 4 ст: Ввод>>).
\item
Все ступени <<ТЗНП>> могут быть выведены из работы оперативно путем активации сигнала оперативного вывода (<<ОВ ТЗНП>>), что характеризуется активным состоянием сигнала <<Оперативный вывод>> (<<ТЗНП 1 ст: Оперативный вывод>>, <<ТЗНП 2 ст: Оперативный вывод>>, <ТЗНП 3 ст: Оперативный вывод>>, <<ТЗНП 4 ст: Оперативный вывод>>) на выходе функции.
\item
При активном состоянии входного сигнала <<ТЗНП 1 ст на сигн>>, <<ТЗНП 2 ст на сигн>>, <<ТЗНП 3 ст на сигн>>, <<ТЗНП 4 ст на сигн>> действие соответствующей ступени ТЗНП переводится на сигнал.

\item
В качестве измерительных органов применяется ИО тока нулевой последовательности максимального действия, которые контролируют превышение тока НП заданной величины с коэффициентом возврата равным 0,95. Выбор режима работы ИО (независимая или обратнозависимая характеристика) осуществляется уставкой характеристики срабатывания <<Характеристика>>.
\item
При срабатывании ИО активируются соответствующие выходные сигналы :
\begin{itemize}
    \item <<ТЗНП 1 ст.: ИО 3I0>>;
    \item <<ТЗНП 2 ст.: ИО 3I0>>;
    \item <<ТЗНП 3 ст.: ИО 3I0>>;
    \item <<ТЗНП 4 ст.: ИО 3I0>>.
\end{itemize}
\item
При срабатывании ИО и выполнении условий логики работы схемы далее формируются выходные сигнала пуска:
\begin{itemize}
    \item <<ТЗНП 1 ст.: Пуск>>;
    \item <<ТЗНП 2 ст.: Пуск>>;
    \item <<ТЗНП 3 ст.: Пуск>>;
    \item <<ТЗНП 4 ст.: Пуск>>.
\end{itemize}
\item
При наличии пусковых условий функции запускается таймер Т1 зависимой/независимой выдержки времени на срабатывание. По истечении выдержки времени Т1, в течение которой величина тока постоянно превышала уровень тока срабатывания, активируются соответствующие выходные сигналы срабатывания:
\begin{itemize}
    \item <<ТЗНП 1 ст.: Срабатывание>>;
    \item <<ТЗНП 2 ст.: Срабатывание>>;
    \item <<ТЗНП 3 ст.: Срабатывание>>;
    \item <<ТЗНП 4 ст.: Срабатывание>>.
\end{itemize}
\item
При выборе режима с зависимыми характеристиками срабатывания активируется измерительный орган с зависимой выдержкой времени. Все характеристики (кроме характеристики RXIDG) в диапазоне значений тока от $ 1,0 \cdot I/I_{\textsl{ср}} $ до $ 1,1 \cdot I/I_{\textsl{ср}} $ имеют независимую выдержку времени на срабатывание ($t_{\textsl{ср.независ.}}= f (I = 1,1 \cdot I/I_{\textsl{ср}})$). При кратности тока выше 20 ($ I/I_{\textsl{ср}} \geq 20 $)  все зависимые характеристики переходят в независимые (кроме характеристики RXIDG) с выдержкой времени срабатывания, равной выдержки времени срабатывания при $ I/I_{\textsl{ср}} = 20 $ ($t_{\textsl{ср.независ.20}}= f (I = 20 \cdot I/I_{\textsl{ср}})$). C помощью временного коэффициента характеристики срабатывания ($K$) имеется возможность регулирования времени срабатывания времятоковых характеристик.

\item
Графики реализованных в устройстве обратнозависимых времятоковых характеристик приведены в приложении \ref{app:chars}.
\item
Ступень ТЗНП имеет возможность выбора направленности. Направленность ступени определяется уставкой SGF2 <<Направленность>>.  Ступень может работать как без контроля направленности, так и с контролем прямого либо обратного направления. Сигналы направления ступень получает от органа направления мощности <<ОНМ НП>>.

\item
Режим контроля направленности при неисправности цепей напряжения задается уставкой SGF4:
\begin{itemize}
    \item если уставка выставлена в положение <<Блокировка>>,  то при наличии активного сигнала неисправности ЦН осуществляется блокировка всех режимов направленности; 
    \item если уставка выставлена в положение <<Деблокировка>>,  то при наличии активного сигнала неисправности ЦН осуществляется разрешение работы во всех режимах направленности. 
\end{itemize}

\item
Ступень может работать с контролем напряжения НП, который осуществляется с помощью настройки уставки SGF6 <<Реж\_3U0>>. При активации контроля НП, пуск ступени возможен только в том случае, если утроенное напряжение нулевой последовательности превышает значение уставки и отсутствует сигнал неисправности от цепей напряжения, когда уставка SGF5 <<Реж\_БНН\_3U0>> находится в положении <<Блокировка>>.

\item
При срабатывании ИО напряжения НП активируются соответствующие выходные сигналы:
\begin{itemize}
    \item <<ТЗНП 1 ст.: ИО 3U0>>;
    \item <<ТЗНП 2 ст.: ИО 3U0>>;
    \item <<ТЗНП 3 ст.: ИО 3U0>>;
    \item <<ТЗНП 4 ст.: ИО 3U0>>.
\end{itemize}

\item
Работа ступени при неисправности цепей напряжения регулируется уставкой SGF5 <<Реж\_БНН\_3U0>>. Уставка может находиться в одном из двух состояний: <<блокировка>> или <<деблокировка>>. В режиме блокировки работа ступени запрещается до момента исчезновения неисправности БНН. В режиме деблокировки появление неисправности в цепях напряжения, контролируемых по входному сигналу <<БННш: Срабатывание>>, позволяет ступени функционировать без учета направления.

\item
При необходимости возможна блокировка ступени при броске тока намагничивания силового трансформатора от функции <<БНТ НП>>, это достигается путем перевода программного переключателя выбора режима контроля от БНТ SGF7 <<Реж\_БНТ>> в положение <<Предусмотрено>>.

\item
Вывод направленности ступени при автоматическом ускорении определяется уставкой SGF4 <<Ненапр\_АУ>>.

\item
Для блокировки чувствительных ступеней при работе в неполнофазном режиме в функции предусмотрена логика блокировки по дискретному входному сигналу <<Блок.чувств.ступ.>>. Блокировка
чувствительных ступеней формируется при введенном ключе <<Блок.чувств.ступ.>> в работу. Ступень блокируется, если уставка SGF8 <<Реж\_БЧС>> разрешает блокировку и на вход поступает сигнал <<Блок.чувств.ступ.>>.

\item Орган направления мощности НП (ОНМ НП)

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
В радиальных сетях, когда собственные емкостные токи отдельных присоединений велики и соизмеримы с полным током сети ненаправленная токовая защита нулевой последовательности не может обеспечить селективность действия. Для селективной работы в таких случаях необходимо применение органа направления мощности нулевой последовательности совместно с измерительным токовым органом защиты.

\item
Функция <<ОНМ НП>> автоматически вводится в работу, если введена в работу одна из ступеней ТЗНП и в этой ступени настроен контроль направленности.

\item
В качестве воздействующих величин ОНМ НП использует значения первой гармоники тока нулевой последовательности и напряжения нулевой последовательности.

\item
Направленный элемент срабатывает при выполнении следующих условий:
\begin{itemize}
    \item напряжение НП превышает 1 вольт;
    \item ток НП превышает значение $0,04 \cdot I_{\textsl{ном}}$ НП;
    \item вектор полной мощности нулевой последовательности, определяемый по углу током НП и напряжением НП, находится в области срабатывания (прямое или обратное направление).
\end{itemize}

\item
Для определения области срабатывания задается уставка $\varphi_{\textsl{м.ч.}}$. Отсчет угла максимальной чувствительности производится от вектора напряжения НП и считается положительным, если направление отсчета совпадает с направлением вращения против часовой стрелки. Угол сектора отсчитывается от угла максимальной чувствительности в обе стороны и составляет 85°.

\item 
Сигнал <<ОНМ НП: Прямое>> появляется, если вектор полной мощности НП находится в диапазоне от $\varphi_{\textsl{м.ч.}}$ - 85° до  $\varphi_{\textsl{м.ч.}}$ + 85°. Сигнал <<ОНМ НП: Обратное>> появляется, если вектор полной мощности НП находится в диапазоне от ($\varphi_{\textsl{м.ч.}}$ - 180°) + 85° до ($\varphi_{\textsl{м.ч.}}$ - 180°) - 85°. Если вектор полной мощности НП находится в зоне <<нечувствительности>>, то ни один из вышеуказанных сигналов не появляется.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%% ОРГАН БНТ %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\item Блокировка при броске намагничивающего тока НП (БНТ НП)

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
Функция блокировки при броске намагничивающего тока НП (<<БНТ НП>>) позволяет заблокировать защиту нулевой последовательности при броске тока намагничивания НП, возникающем при постановке силового трансформатора под напряжение. 
\item
Ввод функции <<БНТ НП>> осуществляется автоматически при активации режим контроля броска тока намагничивания введенной в работу ступени ТЗНП.
\item
Условие пуска выполняется при одновременном наличии следующих условий:
\begin{itemize}
\item отношение действующего значения тока НП второй гармоники (\textsl{3I0 2г}) к действующему значению тока НП первой гармоники (\textsl{3I0}) превышает уставку <<Ih2/Ih1>>;
\item отсутствует срабатывание порогового элемента, реагирующего на превышение действующего значения первой гармоники тока НП (\textsl{3I0}) над уставкой <<Iср>>;
\item сформирован пуск одной из ступеней ТЗНП.
\end{itemize}

\item
Алгоритм работы функции <<БНТ НП>> выполнен в соответствии с рисунком \ref{tznp:img3}. В таблице \ref{tznp:tbl3} приведены параметры, необходимые для настройки функции <<БНТ НП>>.

\item Оперативное ускорение ТЗНП (ОУ ТЗНП)

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic{enumi}.\arabic*, labelsep=4pt, leftmargin=0em, itemindent=65pt, parsep=0pt]

\item
Оперативное ускорение предусматривает ускорение любой ступени ТЗНП. Оперативное ускорение может вводиться:
\begin{itemize}
    \item при выводе основной защиты оборудования;
    \item при опробовании оборудования рабочим напряжением;
    \item при операциях с разъединителями на противоположном конце ВЛ.
\end{itemize}

\item
В данном алгоритме при введенном ключе <<Ввод ОУ ТЗНП>> предусмотрена возможность оперативного ускорения любой ступени ТЗНП. Выбор ускоряемой ступени осуществляется программным переключателем SGF1 <<Выбор\_ст\_ОУ>>. При введенной функции и появлению сигнала пуска выбранной ступени по истечению выдержки времени, определяемой уставкой T1, формируется сигнал срабатывания.
