\color{uniblue}{\subsection{Защита минимального напряжения (ЗМН)}}
\color{black}

\begin{enumerate}[label=\arabic{section}.\arabic{subsection}.\arabic*, labelsep=4pt, leftmargin=0pt, itemindent=57pt]

\item
Функция <<ЗМН>> отслеживает снижение напряжения на секции шин и формирует команду на отключение выключателя. В устройстве предусмотрены две независимые функции ЗМН (ЗМН 1, ЗМН 2).
\item
ЗМН может применяться:
\begin{itemize}
\item в качестве индивидуальной/групповой защиты при потере питания секции шин, действующей на отключение присоединения;
\item для обнаружения провалов напряжения в ЛЭП и в электрических машинах.
\end{itemize}

\item
При снижении ИО напряжения ниже уставки активируются соответствующие выходные сигналы срабатывания ИО:
\begin{itemize}
    \item <<ЗМН 1: ИО Uab>>;
    \item <<ЗМН 1: ИО Ubc>>;
    \item <<ЗМН 1: ИО Uca>>.
\end{itemize}
\item
Посредством уставки SGF2 предоставляется возможность настройки работы функции в одном из трех режимов:
\begin{itemize}
    \item  по снижению одного линейного напряжения;
    \item по снижению двух линейных напряжений;
    \item  по снижению трех линейных напряжений.
\end{itemize}
\item
Обязательным условием формирования выходных сигналов пуска и срабатывания функции является наличие активного сигнала <<В: Включен>>, что исключает работу при отключенном выключателе и отсутствие активного сигнала блокировки от неисправности цепей напряжения ТН <<БНН: Срабатывание>>.

\item
При наличии неисправности в цепях напряжения все функции ЗМН автоматически блокируются.
\item
Уставкой SGF3 в функции предусмотрен контроль симметрии по напряжению обратной последовательности. В режиме работы по трем линейным напряжениям и увеличению напряжения ОП, пуск и срабатывание функции будет заблокировано.
\item
При наличии пусковых условий, срабатывание функции происходит после отсчета выдержки времени, таймера T1.

\item
Ввод 1,2 ступени ЗМН в работу на этапе параметрирования устройства осуществляется программным переключателем SGF1 <<Ввод\_функции>> для каждой ступени. Информация о введенной ступени отображается выходным сигналом <<ЗМН1: Ввод>>, <<ЗМН2: Ввод>>.
\item
Функция <<ЗМН>> может быть выведена из работы оперативно путем активации сигнала <<ОВ ЗМН 1>> <<ОВ ЗМН 2>>, что характеризуется активным состоянием сигнала <<ЗМН 1: Оперативный вывод>>, <<ЗМН 2: Оперативный вывод>>.

\item
При активном состоянии входного сигнала <<ЗМН 1 на сигн>>, <<ЗМН 2 на сигн>> действие функции <<ЗМН>> переводится на сигнал.

\item
Алгоритм работы функции <<ЗМН>> выполнен в соответствии с рисунком \ref{zmn:img1}. В таблице \ref{zmn:tbl1} приведены параметры, необходимые для настройки функции <<ЗМН>>.
